# ЧАСТЬ 1. HTML BASICS

## 1.1 Что такое HTML

>**HTML (HyperText Markup Language)** — язык разметки, описывающий **структуру** и **содержимое** веб-страницы. Это не язык программирования (нет переменных, условий, циклов) — это именно **разметка**: набор тегов, определяющих смысл и структуру частей документа.

Разделение ролей в вебе:

- **HTML** — структура и содержимое ("что это за элемент")
- **CSS** — внешний вид ("как это выглядит")
- **JavaScript** — поведение ("что происходит при взаимодействии")

---

## 1.2 Базовая структура документа

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Заголовок страницы</title>
</head>
<body>
  <h1>Привет, мир!</h1>
</body>
</html>
```

**Разбор:**

- `<!DOCTYPE html>` — объявление типа документа, говорит браузеру использовать современный стандарт HTML5 (без него браузер может включить "quirks mode" — режим совместимости со старыми, нестандартными страницами, что ломает многие CSS-расчёты)
- `<html lang="ru">` — корневой элемент; атрибут `lang` важен для скринридеров (озвучка с правильным произношением/акцентом) и SEO (поисковики понимают язык контента)
- `<head>` — служебная информация, невидимая на странице напрямую: метаданные, подключение стилей/скриптов, заголовок вкладки
- `<body>` — весь видимый контент страницы

## 1.3 Элементы, теги, атрибуты — терминология

```html
<a href="https://example.com" target="_blank">Ссылка</a>
```

- **Тег (tag)** — `<a>` (открывающий) и `</a>` (закрывающий) — сама разметка
- **Элемент (element)** — вся конструкция целиком: открывающий тег + содержимое + закрывающий тег
- **Атрибут (attribute)** — дополнительная информация внутри открывающего тега: `href="..."`, `target="..."`
- **Значение атрибута (attribute value)** — то, что в кавычках: `"https://example.com"`

**Пустые (self-closing) элементы** — не имеют содержимого и закрывающего тега:

```html
<img src="photo.jpg" alt="Описание">
<br>
<input type="text">
<hr>
```

## 1.4 Категории элементов — блочные и строчные

| Block-level (блочные)                                              | Inline (строчные)                                           |
| ------------------------------------------------------------------ | ----------------------------------------------------------- |
| Занимают всю доступную ширину, начинаются с новой строки           | Занимают только необходимую ширину, не переносят строку     |
| `<div>`, `<p>`, `<h1>-<h6>`, `<ul>`, `<li>`, `<section>`           | `<span>`, `<a>`, `<strong>`, `<em>`, `<img>`                |
| Можно задавать `width`/`height`, `margin`/`padding` со всех сторон | `width`/`height` обычно не действуют (кроме `inline-block`) |

**`inline-block`** — гибрид: ведёт себя как строчный элемент в потоке (не переносит строку сам по себе), но при этом можно задавать `width`/`height` как у блочного.

## 1.5 Основные группы тегов (обзор)

### Текстовые

```html
<h1>Заголовок 1 уровня</h1> ... <h6>Заголовок 6 уровня</h6>
<p>Параграф текста</p>
<strong>Важный текст (жирный, семантически значимый)</strong>
<em>Акцентированный текст (курсив, семантически значимый)</em>
<b>Просто жирный (без смысловой нагрузки)</b>
<i>Просто курсив (без смысловой нагрузки)</i>
<br> <!-- перенос строки -->
<hr> <!-- горизонтальная линия-разделитель -->
```

⚠️ **`<strong>`/`<em>` vs `<b>`/`<i>`** — визуально выглядят одинаково (жирный/курсив), но первые несут **смысловую нагрузку** (важность, ударение) — это важно для скринридеров и SEO, вторые — чисто стилистическое оформление без смысла.

### Списки

```html
<ul>              <!-- маркированный (unordered) -->
  <li>Пункт 1</li>
  <li>Пункт 2</li>
</ul>

<ol>              <!-- нумерованный (ordered) -->
  <li>Шаг 1</li>
  <li>Шаг 2</li>
</ol>

<dl>              <!-- список определений -->
  <dt>HTML</dt>
  <dd>Язык разметки</dd>
</dl>
```

### Ссылки и медиа

```html
<a href="page.html">Ссылка</a>
<a href="mailto:test@example.com">Email-ссылка</a>
<a href="tel:+79001234567">Телефонная ссылка</a>

<img src="photo.jpg" alt="Описание фото" width="300" height="200">

<video src="video.mp4" controls></video>
<audio src="audio.mp3" controls></audio>
```

### Таблицы

```html
<table>
  <thead>
    <tr>
      <th>Имя</th>
      <th>Возраст</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Аня</td>
      <td>20</td>
    </tr>
  </tbody>
</table>
```

### Формы

```html
<form action="/submit" method="POST">
  <label for="name">Имя:</label>
  <input type="text" id="name" name="name" required>

  <input type="email" name="email" placeholder="Email">
  <input type="password" name="password">
  <input type="checkbox" name="agree"> Согласен с условиями
  <input type="radio" name="gender" value="male"> Мужской
  <input type="radio" name="gender" value="female"> Женский

  <select name="city">
    <option value="msk">Москва</option>
    <option value="spb">Санкт-Петербург</option>
  </select>

  <textarea name="message"></textarea>

  <button type="submit">Отправить</button>
</form>
```

- `<label for="name">` связан с `<input id="name">` — клик по лейблу фокусирует поле, важно для доступности
- `required` — атрибут встроенной HTML-валидации, браузер не даст отправить форму без заполнения
- `method="POST"` vs `GET` — `POST` отправляет данные в теле запроса (для изменения состояния сервера), `GET` — в URL (для запроса данных, виден в адресной строке, ограничен по длине)

## 1.6 Атрибуты — глобальные и специфичные

**Глобальные** (можно использовать на почти любом элементе):

```html
<div id="unique-id" class="my-class" data-user-id="42" title="Подсказка" hidden></div>
```

- `id` — уникальный идентификатор (должен быть уникален на странице)
- `class` — один или несколько классов через пробел, для стилизации/JS-выборки
- `data-*` — произвольные "пользовательские" атрибуты для хранения данных, доступны в JS через `element.dataset.userId`
- `title` — всплывающая подсказка при наведении
- `hidden` — скрывает элемент (аналог `display: none`)
