# ЧАСТЬ 2. META TAGS

## 2.1 Общее назначение

>**Мета-теги** размещаются внутри `<head>` и содержат метаданные — информацию **о** странице, не являющуюся видимым содержимым, но важную для браузера, поисковых систем, социальных сетей.

## 2.2 Обязательные/базовые мета-теги

```html
<meta charset="UTF-8">
```

Кодировка документа. **Всегда должна идти одной из первых строк** в `<head>` — если браузер начнёт читать документ в неправильной кодировке, могут появиться "кракозябры" ещё до того, как он доберётся до этого тега.

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

Критически важен для адаптивной (responsive) вёрстки — сообщает мобильным браузерам использовать реальную ширину экрана устройства вместо эмуляции "десктопной" ширины с последующим уменьшением масштаба. Без него мобильная адаптивность через CSS media-запросы работать не будет как надо.

- `width=device-width` — ширина вьюпорта = ширина экрана устройства
- `initial-scale=1.0` — начальный уровень зума

## 2.3 SEO-мета-теги

```html
<title>Название страницы — Название сайта</title>
<meta name="description" content="Краткое описание страницы для поисковой выдачи, обычно до 150-160 символов">
<meta name="keywords" content="ключевые, слова"> <!-- сегодня почти игнорируется поисковиками, историческое наследие -->
<link rel="canonical" href="https://example.com/page">
```

- `<title>` — не совсем мета-тег технически, но критически важен для SEO и вкладок браузера
- `description` — часто именно этот текст показывается под заголовком в результатах поиска
- `canonical` — указывает "основной" URL страницы, если один и тот же контент доступен по нескольким адресам (защита от дублирования контента в глазах поисковика)

## 2.4 Open Graph — превью при шеринге в соцсетях

```html
<meta property="og:title" content="Заголовок для соцсетей">
<meta property="og:description" content="Описание для соцсетей">
<meta property="og:image" content="https://example.com/preview.jpg">
<meta property="og:url" content="https://example.com/page">
<meta property="og:type" content="website">
```

Именно эти теги определяют, как будет выглядеть карточка-превью, когда ссылку на страницу кидают в Facebook, Telegram, LinkedIn и т.д. Без `og:image`, например, превью может быть без картинки или с произвольным изображением со страницы.

```html
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="Заголовок">
<meta name="twitter:image" content="https://example.com/preview.jpg">
```

Аналогичный набор специально для Twitter/X (частично пересекается с Open Graph, но иногда нужен отдельно).

## 2.5 Прочие практически важные мета-теги

```html
<meta name="robots" content="index, follow">
```

Указания поисковым роботам: индексировать ли страницу (`index`/`noindex`) и переходить ли по ссылкам на ней (`follow`/`nofollow`).

```html
<link rel="icon" href="/favicon.ico" type="image/x-icon">
```

Favicon — иконка вкладки браузера (технически `<link>`, а не `<meta>`, но всегда рассматривается в этом же контексте).

```html
<meta name="theme-color" content="#317EFB">
```

Цвет адресной строки браузера на мобильных устройствах (Android Chrome и т.д.) — влияет на визуальную интеграцию сайта с UI браузера.

```html
<meta http-equiv="refresh" content="30">
```

Автоматическое обновление страницы через N секунд (используется редко, обычно не лучшая практика для UX).
