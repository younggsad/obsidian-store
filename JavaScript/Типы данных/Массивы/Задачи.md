
## Длина массива и empty slots 

```javascript
const arr = [1, 2, 3];

arr.length = 1;

console.log(arr);
console.log(arr[1]);
console.log(arr.length);
```

Выведет:

```
[1]
undefined
1
```

Когда ты делаешь:

```javascript
arr.length = 1;
```

JavaScript **не заменяет элементы на `undefined`**.

Он **удаляет элементы**, индексы которых больше или равны новой длине.

То есть массив становится:

```
[1]
```

Элементов `2` и `3` больше не существует.

Проверка:

```javascript
const arr = [1, 2, 3];

arr.length = 1;

console.log(1 in arr); // false
console.log(2 in arr); // false
```

Они действительно удалены.

---

## А почему тогда

```javascript
arr[1]
```

дает

```
undefined
```

Потому что свойства с индексом `1` больше нет.

Это то же самое, что написать:

```javascript
const obj = {};

console.log(obj.foo);
```

Получишь:

```
undefined
```

---

## Как это работает внутри?

Важно понимать, что массив в JavaScript — это **специальный объект**.

Например:

```javascript
const arr = ["a", "b"];
```

приблизительно выглядит как:

```javascript
{
  0: "a",
  1: "b",
  length: 2
}
```

Когда ты пишешь:

```javascript
arr.length = 1;
```

движок удаляет все свойства с индексом ≥ 1:

```javascript
{
  0: "a",
  length: 1
}
```

Разберем.

```javascript
const arr = [1];

arr.length = 5;

console.log(arr);
console.log(arr[3]);
console.log(arr.length);
```

Вывод:

```javascript
[1, <4 empty items>]   // или [1, empty × 4] — зависит от среды
undefined
5
```

---

## Что произошло?

Изначально:

```javascript
arr = [1]
```

После:

```javascript
arr.length = 5;
```

JavaScript **не создает**:

```javascript
[1, undefined, undefined, undefined, undefined]
```

и тем более не создает:

```javascript
[1, null, null, null, null]
```

Он просто увеличивает длину массива.

Получаются **пустые ячейки (holes / empty slots)**.

---

## Почему это важно?

Потому что:

```javascript
console.log(arr[3]);
```

выведет

```
undefined
```

Но это **не означает**, что там лежит `undefined`.

Проверим:

```javascript
const arr = [1];
arr.length = 5;

console.log(3 in arr);
```

Результат:

```javascript
false
```

То есть свойства с индексом `3` вообще **не существует**.

---

А теперь сравни:

```javascript
const arr = [1];

arr[3] = undefined;

console.log(3 in arr);
```

Получим:

```javascript
true
```

Потому что свойство существует, просто его значение — `undefined`.

Это две разные ситуации.

```javascript
const arr = new Array(3);

console.log(arr);

arr.forEach(() => console.log("Hi"));

console.log(arr.map(() => 1));
```

Результат примерно такой:

```
[ <3 empty items> ]
[ <3 empty items> ]
```

И **ни одного** `"Hi"`.

---

## Почему?

### Шаг 1

```javascript
const arr = new Array(3);
```

Это **не**

```
[undefined, undefined, undefined]
```

Это массив с тремя **пустыми слотами**.

У него:

```javascript
arr.length === 3
```

Но свойств:

```
0
1
2
```

вообще нет.

Проверка:

```javascript
0 in arr // false
1 in arr // false
2 in arr // false
```

---

## Почему `forEach` ничего не делает?

`forEach` проходит только по **существующим элементам**.

Поскольку элементов нет:

```javascript
arr.forEach(...)
```

не вызывает callback **ни разу**.

---

## Почему `map` тоже ничего не делает?

`map` тоже пропускает пустые слоты.

Поэтому он возвращает массив **той же длины**, но с такими же пустыми слотами.

То есть:

```javascript
arr.map(() => 1)
```

не станет:

```
[1, 1, 1]
```

а останется:

```
[ <3 empty items> ]
```

---

## А как получить `[1, 1, 1]`?

Есть несколько способов.

Например:

```javascript
Array.from({ length: 3 }, () => 1);
```

или

```javascript
new Array(3).fill(1);
```

или

```javascript
Array(3).fill().map(() => 1);
```

Потому что `fill()` создаст реальные элементы массива.
