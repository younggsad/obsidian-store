## Что такое Garbage Collector (GC)

> Garbage Collector — это механизм автоматического управления памятью в JavaScript. Он удаляет объекты, которые больше недостижимы из корневых ссылок. Основной принцип основан на достижимости: пока на объект есть ссылка из активного кода, он остается в памяти. Замыкания могут удерживать данные в памяти, потому что функция хранит ссылку на свое лексическое окружение.

Разработчик сам не пишет:

```javascript
delete memory
free()
```

Движок сам определяет, какие данные больше не нужны.

---

## Главный принцип: Reachability (достижимость)

GC не смотрит:

> "Использовался ли объект недавно?"

Он смотрит:

> **Можно ли до объекта добраться из корневых объектов?**

Корневые объекты (roots):

- глобальные переменные;
- текущие переменные в Call Stack;
- активные замыкания;
- некоторые внутренние ссылки движка.

Пример:

```javascript
let user = {
  name: "Alex"
};
```

Пока существует:

```
user
```

объект достижим:

```
Global
  |
  ↓
 user
  |
  ↓
{name: "Alex"}
```

GC его не удалит.

---

Теперь:

```javascript
user = null;
```

Получаем:

```javascript
Global

(no references)

{name: "Alex"}
```

До объекта больше нельзя добраться.

Он становится кандидатом на удаление.

---

## Теперь про замыкания

Вот где связываются наши предыдущие темы.

```javascript
function createUser() {
  const user = {
    name: "Alex"
  };

  return function() {
    console.log(user.name);
  };
}

const fn = createUser();
```

После выполнения `createUser()`:

Функция закончилась.

Но:

```
fn
 |
 ↓
Function
 |
[[Environment]]
 |
 ↓
user object
```

`user` все еще достижим.

Поэтому GC его НЕ удалит.

---

Если сделать:

```javascript
fn = null;
```

Теперь:

```
Function
     X

user object
     X
```

и объект можно удалить.

---

## А циклические ссылки?

Старый миф:

```javascript
const a = {};
const b = {};

a.b = b;
b.a = a;
```

Раньше некоторые сборщики мусора могли с этим иметь проблемы.

Но современные GC используют алгоритмы типа:

> Mark-and-Sweep

Они ищут не просто циклы, а **достижимость от корней**.

Если:

```javascript
a = null;
b = null;
```

то цикл существует:

```
a → b
↑   ↓
└───┘
```

но снаружи никто туда не может попасть.

Значит:

```javascript
unreachable
```

и память будет освобождена.
