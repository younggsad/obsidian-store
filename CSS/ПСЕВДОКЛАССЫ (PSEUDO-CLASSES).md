# ЧАСТЬ 2. ПСЕВДОКЛАССЫ (PSEUDO-CLASSES)

## 2.1 Общее определение

>**Псевдокласс** — выбирает элементы, находящиеся в определённом **состоянии** или **позиции**, которое невозможно выразить через обычную структуру HTML/классы. Синтаксис — одно двоеточие: `:псевдокласс`.

## 2.2 Псевдоклассы состояния (интерактивные)

```css
a:link { color: blue; }         /* непосещённая ссылка */
a:visited { color: purple; }      /* посещённая ссылка */
a:hover { color: red; }             /* курсор наведён */
a:active { color: orange; }           /* элемент в момент клика (нажат) */
a:focus { outline: 2px solid blue; }  /* элемент получил фокус (клавиатура/клик) */
a:focus-visible { outline: 2px solid blue; } /* фокус ТОЛЬКО от клавиатуры, не от клика мышью — лучше для доступности */

input:disabled { opacity: 0.5; }
input:enabled { }
input:checked { }                /* чекбокс/радио отмечены */
input:required { }
input:valid { border-color: green; }    /* прошло HTML-валидацию */
input:invalid { border-color: red; }
input:placeholder-shown { }     /* поле показывает placeholder (то есть пустое) */
```

⚠️ **Порядок важен** для ссылок — принято мнемоническое правило **LVHA**: `:link → :visited → :hover → :active`. Если поменять порядок, более поздние правила будут перебивать более ранние из-за одинаковой специфичности, и `:hover`, например, может вообще перестать работать для посещённых ссылок.

## 2.3 Структурные псевдоклассы (по позиции в DOM)

```css
li:first-child { }             /* первый ребёнок среди ЛЮБЫХ соседей */
li:last-child { }
li:nth-child(2) { }              /* конкретно второй по счёту среди ВСЕХ типов соседей */
li:nth-child(odd) { }              /* все нечётные (1, 3, 5...) */
li:nth-child(even) { }               /* все чётные (2, 4, 6...) */
li:nth-child(3n) { }                   /* каждый третий (3, 6, 9...) */
li:nth-child(3n+1) { }                    /* формула: 1, 4, 7, 10... */

li:first-of-type { }             /* первый СРЕДИ ЭЛЕМЕНТОВ ТОГО ЖЕ ТИПА тега */
li:last-of-type { }
li:nth-of-type(2) { }

:only-child { }                  /* единственный ребёнок у родителя */
:empty { }                         /* элемент без содержимого вообще */
```

**`:nth-child` vs `:first-of-type`** — частая путаница. `:first-child` смотрит на позицию среди **всех** соседей, независимо от тега; `:first-of-type` — на позицию среди соседей **того же тега**.

```html
<div>
  <h2>Заголовок</h2>
  <p>Первый параграф</p>  <!-- НЕ :first-child (первый ребёнок — h2), НО :first-of-type для <p> -->
</div>
```

## 2.4 Логические псевдоклассы

```css
:not(.active) { }                     /* всё, КРОМЕ элементов с классом .active */
:is(h1, h2, h3) { color: navy; }        /* сокращает запись — эквивалент "h1, h2, h3", но с меньшей специфичностью влияния родителя */
:where(h1, h2, h3) { color: navy; }       /* как :is(), но специфичность ВСЕГДА равна нулю — удобно для "сбрасываемых" базовых стилей */
:has(> img) { border: 1px solid; }         /* родитель, у которого ЕСТЬ дочерний элемент по условию ("родительский селектор") */
```

`:has()` — относительно новая, но мощная возможность: впервые в CSS появился способ стилизовать **родителя** на основе его **потомков** — раньше это было невозможно без JS.

```css
/* Пример: карточка со специальной рамкой, ЕСЛИ внутри есть изображение */
.card:has(img) {
  border: 2px solid gold;
}
```

## 2.5 Прочие полезные псевдоклассы

```css

:target { }                 /* элемент, на который указывает текущий якорь URL (#section) */
::selection { }               /* технически псевдоэл
```
