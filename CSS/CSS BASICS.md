# ЧАСТЬ 1. CSS BASICS

## 1.1 Что такое CSS и как он подключается

**CSS (Cascading Style Sheets)** — язык, описывающий **внешний вид** HTML-элементов: цвета, отступы, шрифты, расположение на странице.

### Способы подключения

```html
<!-- 1. Внешний файл — предпочтительный способ -->
<link rel="stylesheet" href="styles.css">

<!-- 2. Внутри документа -->
<style>
  p { color: blue; }
</style>

<!-- 3. Инлайн-стиль на конкретном элементе — наименее предпочтительный -->
<p style="color: blue;">Текст</p>
```

Внешние файлы предпочтительны: браузер кэширует их отдельно от HTML, стили переиспользуются между страницами, легче поддерживать.

## 1.2 Синтаксис и селекторы

```css
селектор {
  свойство: значение;
  свойство2: значение2;
}
```

### Основные типы селекторов

```css
p { }                  /* по тегу */
.my-class { }           /* по классу */
#unique-id { }           /* по id */
* { }                     /* универсальный — все элементы */

/* Комбинаторы */
div p { }                /* потомок (любого уровня вложенности) */
div > p { }               /* прямой потомок (непосредственный ребёнок) */
h1 + p { }                  /* соседний элемент СРАЗУ после (соседний-сиблинг) */
h1 ~ p { }                    /* все последующие элементы-соседи (общий сиблинг) */

/* Группировка и атрибуты */
h1, h2, h3 { }              /* применить одинаковые стили к нескольким селекторам */
input[type="text"] { }        /* по значению атрибута */
a[href^="https"] { }           /* атрибут НАЧИНАЕТСЯ с значения */
a[href$=".pdf"] { }             /* атрибут ЗАКАНЧИВАЕТСЯ значением */
a[href*="example"] { }           /* атрибут СОДЕРЖИТ значение */
```

## 1.3 Специфичность (Specificity) — кто победит при конфликте правил

Когда несколько правил CSS применяются к одному и тому же элементу с конфликтующими значениями, побеждает правило с более высокой **специфичностью**.

Расчёт специфичности — по 4 категориям, от самой значимой к наименее:

|Категория|Вес|
|---|---|
|`!important`|перебивает всё (использовать крайне осторожно)|
|Инлайн-стиль (`style="..."`)|1,0,0,0|
|ID-селекторы (`#id`)|0,1,0,0|
|Классы, атрибуты, псевдоклассы (`.class`, `[attr]`, `:hover`)|0,0,1,0|
|Теги, псевдоэлементы (`div`, `::before`)|0,0,0,1|

```css
p { color: black; }              /* специфичность: 0,0,0,1 */
.text { color: blue; }             /* специфичность: 0,0,1,0 — победит над предыдущим */
#main { color: red; }               /* специфичность: 0,1,0,0 — победит над классом */
```

Если специфичность одинакова — побеждает правило, объявленное **позже** в коде (каскад по порядку следования).

**Практический совет:** избегай `!important` и глубокой вложенности селекторов (`.a .b .c .d { }`) — это делает специфичность непредсказуемой и трудноуправляемой в большом проекте. Держи специфичность максимально плоской, предпочитай классы.

## 1.4 Box Model (модель блока)

Каждый HTML-элемент представлен как прямоугольная коробка, состоящая из четырёх слоёв:

```
┌─────────────────────────────┐
│           margin             │  внешний отступ (вне границы, прозрачный)
│  ┌───────────────────────┐  │
│  │        border          │  │  граница
│  │  ┌─────────────────┐  │  │
│  │  │     padding      │  │  │  внутренний отступ (внутри границы)
│  │  │  ┌───────────┐  │  │  │
│  │  │  │  content   │  │  │  │  само содержимое (текст, картинка)
│  │  │  └───────────┘  │  │  │
│  │  └─────────────────┘  │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

```css
.box {
  width: 200px;
  padding: 20px;
  border: 2px solid black;
  margin: 10px;
}
```

### `box-sizing` — критически важное свойство

```css
.box {
  box-sizing: content-box;  /* ПО УМОЛЧАНИЮ: width применяется ТОЛЬКО к content;
                        итоговая видимая ширина = width + padding*2 + border*2 */
}

.box {
  box-sizing: border-box;    /* width включает padding И border;
                        итоговая видимая ширина = ИМЕННО width, без сюрпризов */
}
```

**Практическая рекомендация** — почти всегда ставят глобально:

```css
*, *::before, *::after {
  box-sizing: border-box;
}
```

Это делает расчёт размеров предсказуемым: `width: 200px` означает ровно `200px` на экране, независимо от `padding`/`border`.

## 1.5 Позиционирование (`position`)

```css
.static   { position: static; }    /* ПО УМОЛЧАНИЮ — обычный поток документа, top/left не действуют */
.relative { position: relative; }   /* смещается ОТНОСИТЕЛЬНО своего обычного места, место в потоке сохраняется */
.absolute { position: absolute; }    /* убирается из потока, позиционируется относительно ближайшего НЕ-static предка */
.fixed    { position: fixed; }        /* убирается из потока, позиционируется относительно ОКНА БРАУЗЕРА, не двигается при скролле */
.sticky   { position: sticky; }        /* гибрид: ведёт себя как relative, пока не достигнет заданного порога при скролле, затем "прилипает" как fixed */
```

```css
.parent {
  position: relative;   /* создаёт "точку отсчёта" для абсолютно позиционированных детей */
}
.child {
  position: absolute;
  top: 10px;
  right: 10px;      /* позиционируется относительно .parent, а не всей страницы */
}
```

## 1.6 Flexbox — одномерная раскладка

```css
.container {
  display: flex;
  flex-direction: row;        /* row (по умолчанию) | row-reverse | column | column-reverse */
  justify-content: center;      /* выравнивание по ГЛАВНОЙ оси: flex-start | center | space-between | space-around | space-evenly */
  align-items: center;           /* выравнивание по ПОПЕРЕЧНОЙ оси: stretch (по умолчанию) | flex-start | center | flex-end */
  flex-wrap: wrap;                 /* nowrap (по умолчанию) | wrap — переносить элементы на новую строку */
  gap: 16px;                        /* отступ между элементами */
}

.item {
  flex-grow: 1;      /* насколько элемент может РАСТИ относительно других (0 = не растёт) */
  flex-shrink: 1;      /* насколько может СЖИМАТЬСЯ при нехватке места */
  flex-basis: 200px;    /* базовый размер до распределения свободного места */
  flex: 1 1 200px;        /* сокращённая запись: grow shrink basis */
}
```

**Главная и поперечная оси** — при `flex-direction: row` главная ось горизонтальна (`justify-content` управляет по ней), поперечная вертикальна (`align-items`); при `column` — наоборот.

## 1.7 CSS Grid — двумерная раскладка

```css
.container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;   /* 3 колонки: средняя вдвое шире остальных */
  grid-template-rows: 100px auto;         /* фиксированная высота первой строки, авто для второй */
  gap: 16px;
}

.item {
  grid-column: 1 / 3;   /* элемент занимает колонки с 1-й линии до 3-й (то есть 2 колонки) */
  grid-row: 1 / 2;
}
```

```css
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);   /* 3 равные колонки */
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); /* адаптивная сетка без media-запросов */
}
```

**Flexbox vs Grid — когда что использовать:** Flexbox — для одномерных раскладок (в ряд или в столбец, например навигация, список карточек в одну линию). Grid — для двумерных раскладок (когда важны и строки, и колонки одновременно, например макет всей страницы).

## 1.8 Единицы измерения

|Единица|Тип|Особенность|
|---|---|---|
|`px`|абсолютная|фиксированный размер в пикселях|
|`%`|относительная|относительно родителя|
|`em`|относительная|относительно `font-size` **родителя** (накопительный эффект при вложенности)|
|`rem`|относительная|относительно `font-size` **корневого** элемента (`html`) — предсказуемее, чем `em`|
|`vw`/`vh`|относительная|1% ширины/высоты **вьюпорта** (видимой области окна)|
|`vmin`/`vmax`|относительная|1% от меньшей/большей стороны вьюпорта|

**Практическая рекомендация:** `rem` для размеров шрифтов и отступов (предсказуемо масштабируется вместе с базовыми настройками пользователя), `px` для мелких деталей типа border, `%`/`vw`/`vh` для адаптивных размеров относительно контейнера/экрана.

## 1.9 Адаптивность — Media Queries

```css
/* Mobile-first подход — базовые стили для мобильных, расширения для больших экранов */
.container {
  width: 100%;
}

@media (min-width: 768px) {
  .container {
    width: 750px;
  }
}

@media (min-width: 1024px) {
  .container {
    width: 960px;
  }
}
```

**Mobile-first** (`min-width`) считается лучшей практикой по сравнению с Desktop-first (`max-width`) — базовая версия сайта по умолчанию лёгкая и работает на самых ограниченных устройствах, а стили "утяжеляются" по мере роста экрана, а не наоборот.
