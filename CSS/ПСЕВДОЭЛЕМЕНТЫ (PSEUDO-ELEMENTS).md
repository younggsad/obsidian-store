# ЧАСТЬ 3. ПСЕВДОЭЛЕМЕНТЫ (PSEUDO-ELEMENTS)

## 3.1 Общее определение и отличие от псевдоклассов

>**Псевдоэлемент** — позволяет стилизовать конкретную **часть** элемента, которая не существует как отдельный узел в DOM, либо создать полностью новый "виртуальный" элемент, не добавляя лишней разметки в HTML. Синтаксис — два двоеточия: `::псевдоэлемент` (хотя одно двоеточие тоже до сих пор работает для старых псевдоэлементов, ради обратной совместимости — но `::` считается правильным современным стандартом, отличающим их от псевдоклассов).

**Ключевое концептуальное отличие:**

- Псевдокласс — выбирает **существующий** элемент в особом **состоянии**
- Псевдоэлемент — стилизует **часть** элемента или создаёт **новый**, виртуальный узел

## 3.2 `::before` и `::after` — самые используемые

```css
.quote::before {
  content: "«";
  color: gray;
}
.quote::after {
  content: "»";
  color: gray;
}
```

```html
<span class="quote">Цитата</span>
<!-- Визуально: «Цитата» — кавычки добавлены БЕЗ изменения HTML-разметки -->
```

**Обязательное правило:** `content` — обязательное свойство для `::before`/`::after`, без него псевдоэлемент не отобразится вообще, даже если заданы другие стили. Значение может быть пустой строкой (`content: "";`) — часто используется для чисто декоративных фигур:

```css
.badge::before {
  content: "";
  display: inline-block;
  width: 8px;
  height: 8px;
  border-radius: 50%;
  background: green;
  margin-right: 6px;
}
```

Такой приём — частый способ добавить декоративный элемент (иконку-точку, стрелку, декоративную рамку) без создания лишнего `<span>` в HTML — держит разметку чище, семантичнее.

## 3.3 Остальные псевдоэлементы

```css
p::first-line { font-weight: bold; }    /* стилизация только первой СТРОКИ текста (пересчитывается динамически при resize) */
p::first-letter { font-size: 2em; }        /* стилизация только первой БУКВЫ (эффект "буквицы", как в газетах) */

::selection { background: yellow; }          /* фон выделенного пользователем текста */
input::placeholder { color: gray; }             /* стилизация текста-подсказки в пустом поле ввода */

::marker { color: red; }                          /* маркер элемента списка (точка/цифра перед li) */

::backdrop { background: rgba(0,0,0,0.5); }         /* затемнение фона за модальным окном, открытым через <dialog> или Fullscreen API */
```

## 3.4 Практический пример — кастомный чекбокс через псевдоэлементы

```html
<label class="custom-checkbox">
  <input type="checkbox">
  <span class="checkmark"></span>
  Согласен с условиями
</label>
```

```css
.custom-checkbox input {
  display: none; /* скрываем стандартный чекбокс */
}

.checkmark {
  display: inline-block;
  width: 20px;
  height: 20px;
  border: 2px solid gray;
  position: relative;
}

.custom-checkbox input:checked + .checkmark::after {
  content: "✓";
  position: absolute;
  top: -2px;
  left: 3px;
  color: green;
}
```

Тут комбинируются и псевдокласс (`:checked` — состояние), и псевдоэлемент (`::after` — виртуальный элемент "галочки"), и комбинатор-сосед (`+`) — типичный паттерн для кастомизации стандартных элементов форм.
