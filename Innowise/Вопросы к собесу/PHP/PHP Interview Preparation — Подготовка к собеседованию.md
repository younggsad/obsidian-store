# Part 1. Основы PHP (PHP Fundamentals)

## 1. Введение в PHP (Introduction to PHP)

### Теория

**PHP (PHP: Hypertext Preprocessor)** — это интерпретируемый серверный язык программирования общего назначения, который преимущественно используется для веб-разработки.

PHP выполняется на сервере. Сервер обрабатывает PHP-код и отправляет клиенту результат выполнения, обычно в виде HTML или JSON.

Основные области применения PHP:

- Разработка динамических веб-сайтов.
    
- Создание REST API.
    
- Разработка Backend-приложений.
    
- Создание CMS (Drupal, WordPress).
    
- Разработка интернет-магазинов.
    
- Автоматизация задач и CLI-скрипты.
    
- Обработка фоновых задач.
    

### Как работает PHP

Типичный процесс обработки HTTP-запроса:

1. Клиент отправляет HTTP-запрос.
    
2. Веб-сервер (Nginx или Apache) принимает запрос.
    
3. Веб-сервер передаёт выполнение PHP через PHP-FPM.
    
4. PHP выполняет код приложения.
    
5. Приложение при необходимости взаимодействует с базой данных или внешними сервисами.
    
6. PHP формирует ответ.
    
7. Веб-сервер отправляет ответ клиенту.
    

```
Client (Browser)
       |
       | HTTP Request
       v
Web Server (Nginx)
       |
       v
PHP-FPM
       |
       v
PHP Application
       |
       v
Database (MySQL)
       |
       v
PHP Response
       |
       v
Client (Browser)
```

### Модель выполнения PHP

В традиционной конфигурации PHP-FPM используется модель обработки отдельных запросов.

Каждый HTTP-запрос обрабатывается PHP-воркером. После завершения запроса выполнение заканчивается, а воркер может быть использован повторно для другого запроса.

Обычные переменные приложения не сохраняют своё состояние между независимыми HTTP-запросами автоматически.

### Основные версии PHP

|Версия|Основные возможности|
|---|---|
|PHP 7.0|Скалярная типизация, типы возвращаемых значений|
|PHP 7.4|Типизированные свойства, Arrow Functions|
|PHP 8.0|Union Types, Named Arguments, Attributes, Match, Constructor Property Promotion|
|PHP 8.1|Enums, Readonly Properties, Fibers, Intersection Types|
|PHP 8.2|Readonly Classes, DNF Types, Deprecation динамических свойств|
|PHP 8.3|Typed Class Constants, дополнительные возможности языка|
|PHP 8.4|Property Hooks, Asymmetric Visibility|

### Практика

Простейшая PHP-программа:

```
<?php

$name = 'John';

echo "Hello, {$name}!";
```

Результат:

```
Hello, John!
```

PHP также может генерировать HTML:

```
<?php

$title = 'My Website';

?>

<!DOCTYPE html>
<html>
<head>
    <title><?= htmlspecialchars($title) ?></title>
</head>
<body>
    <h1>Welcome to my website</h1>
</body>
</html>
```

Конструкция `<?=` является сокращённой записью `echo`.

### Вопросы на собеседовании

**1. Что такое PHP?**

PHP — это серверный язык программирования, преимущественно используемый для веб-разработки. Он выполняется на сервере, обрабатывает запросы, взаимодействует с базами данных и генерирует ответы клиенту, например HTML или JSON.

**2. PHP — компилируемый или интерпретируемый язык?**

PHP часто называют интерпретируемым языком, однако внутри он использует компиляцию. Исходный код преобразуется в Opcodes, которые затем выполняются Zend VM (виртуальной машиной Zend).

**3. Чем отличаются Client-side и Server-side языки?**

Client-side код выполняется непосредственно в браузере пользователя. Например, JavaScript.

Server-side код выполняется на сервере. Например, PHP. Он отвечает за бизнес-логику, работу с базой данных, авторизацию и формирование ответов.

**4. Что происходит, когда пользователь открывает PHP-страницу?**

Браузер отправляет HTTP-запрос. Веб-сервер передаёт его PHP-FPM, который запускает PHP-код. Приложение обрабатывает запрос, при необходимости обращается к базе данных и формирует ответ. Затем сервер отправляет его браузеру.

**5. Можно ли использовать PHP для создания REST API?**

Да. PHP поддерживает обработку HTTP-запросов, валидацию данных, бизнес-логику, работу с базами данных и формирование JSON-ответов. Для этого используются Symfony, Laravel и другие инструменты.

## 2. Синтаксис PHP (PHP Syntax)

### Теория

PHP-код размещается внутри специальных открывающих и закрывающих тегов.

```
<?php

// PHP code

?>
```

- `<?php` — начало PHP-кода.
    
- `?>` — конец PHP-кода.
    

Закрывающий тег необязателен в файлах, содержащих только PHP-код.

> [!tip] Рекомендация  
> В PHP-файлах, содержащих только PHP-код, рекомендуется не использовать закрывающий тег `?>`. Это предотвращает случайный вывод пробелов и других символов.

### Инструкции (Statements)

Большинство инструкций PHP заканчиваются точкой с запятой `;`.

```
<?php

$name = 'John';
$age = 25;

echo $name;
echo $age;
```

### Комментарии

PHP поддерживает несколько видов комментариев.

**Однострочные:**

```
// Однострочный комментарий

# Также однострочный комментарий
```

**Многострочные:**

```
/*
Это многострочный
комментарий
*/
```

**PHPDoc:**

Используется для документирования функций, классов, параметров и возвращаемых значений.

```
/**
 * Вычисляет общую стоимость.
 *
 * @param float $price
 * @param int $quantity
 * @return float
 */
function calculateTotal(float $price, int $quantity): float
{
    return $price * $quantity;
}
```

PHPDoc полезен для IDE, статического анализа и документирования сложного кода.

### Вывод информации

|Функция|Назначение|
|---|---|
|`echo`|Выводит одну или несколько строк|
|`print`|Выводит строку и возвращает 1|
|`var_dump()`|Выводит тип и значение|
|`print_r()`|Выводит удобное для чтения представление данных|

```
<?php

echo 'Hello';

print 'World';

var_dump(123);

print_r(['apple', 'banana']);
```

### Чувствительность к регистру

В PHP некоторые элементы чувствительны к регистру, а некоторые нет.

- Имена переменных чувствительны к регистру.
    
- Имена функций в общем случае не чувствительны к регистру.
    
- Имена классов также в общем случае не чувствительны к регистру на уровне языка.
    
- Ключевые слова PHP не чувствительны к регистру.
    

Однако при использовании PSR-4 и файловой системы важно соблюдать единый регистр имён классов и файлов.

```
<?php

$name = 'John';
$Name = 'Alex';

echo $name; // John
echo $Name; // Alex
```

### Вопросы на собеседовании

**1. Для чего нужны PHP-теги?**

Они определяют начало и конец PHP-кода внутри файла. Закрывающий тег можно опускать в файлах, содержащих только PHP-код.

**2. Чем отличаются echo и print?**

Обе конструкции выводят информацию. `echo` может принимать несколько аргументов и не возвращает значение. `print` принимает один аргумент и возвращает `1`.

**3. Чем отличаются var_dump() и print_r()?**

`var_dump()` показывает тип и значение переменной. `print_r()` выводит более удобное для чтения представление данных, особенно массивов и объектов.

**4. Чувствительны ли переменные PHP к регистру?**

Да. `$name` и `$Name` — две разные переменные.

## 3. Переменные и константы (Variables and Constants)

### Теория

**Переменная (Variable)** — это именованная область хранения значения, с которым программа может работать во время выполнения.

В PHP имя переменной начинается со знака `$`.

### Правила именования переменных

- Переменная должна начинаться с `$`.
    
- После `$` должна идти буква или символ `_`.
    
- Имя не может начинаться с цифры.
    
- Допускаются буквы, цифры и символ `_`.
    
- Имена переменных чувствительны к регистру.
    

```
<?php

$name = 'John';
$age = 25;
$user_name = 'john_doe';

// Некорректные варианты:
// $2name = 'John';
// $user-name = 'John';
```

### Присваивание переменных

Для присваивания используется оператор `=`.

```
<?php

$number = 10;

$number = 20;

echo $number; // 20
```

Значение переменной можно изменять во время выполнения программы.

### Константы (Constants)

**Константа** — это именованное значение, которое нельзя переопределить после определения.

В PHP существует два основных способа объявления констант.

**1. Использование define():**

```
<?php

define('APP_NAME', 'My Application');

echo APP_NAME;
```

**2. Использование const:**

```
<?php

const APP_VERSION = '1.0.0';

echo APP_VERSION;
```

### Разница между const и define()

|Характеристика|const|define()|
|---|---|---|
|Тип|Конструкция языка|Функция|
|Определение|На этапе компиляции|Во время выполнения|
|Глобальные константы|Да|Да|
|Условное объявление|Нет|Да|
|Константы классов|Да|Нет|
|Константы пространств имён|Да|Да|

Пример условного определения:

```
<?php

if (!defined('APP_ENV')) {
    define('APP_ENV', 'production');
}
```

### Константы классов (Class Constants)

Константы могут принадлежать определённому классу.

```
<?php

class Database
{
    public const HOST = 'localhost';

    public const PORT = 3306;
}

echo Database::HOST;
```

Начиная с PHP 8.3 поддерживаются типизированные константы классов.

```
<?php

class Config
{
    public const string ENVIRONMENT = 'production';
}
```

### Переменные переменных (Variable Variables)

PHP поддерживает переменные переменных. Это позволяет динамически формировать имя переменной на основе значения другой переменной.

```
<?php

$name = 'username';

$$name = 'John';

echo $username; // John
```

В этом примере `$$name` создаёт переменную `$username`.

В современной разработке такая возможность используется редко, поскольку может усложнять чтение и поддержку кода.

### Вопросы на собеседовании

**1. Чем отличается переменная от константы?**

Переменная может менять своё значение во время выполнения программы. Константа после определения не может быть переопределена.

**2. Чем отличаются const и define()?**

`const` — конструкция языка, которая обрабатывается на этапе компиляции. `define()` — функция, которая определяет константу во время выполнения. `define()` можно использовать внутри условных конструкций.

**3. Можно ли изменить значение константы?**

Нет. После определения константу нельзя переопределить.

**4. Что такое Variable Variables?**

Это механизм, позволяющий динамически создавать или обращаться к переменным, используя значение другой переменной в качестве имени.

## 4. Типы данных (Data Types)

### Теория

PHP является динамически типизированным языком. Это означает, что разработчику необязательно заранее указывать тип переменной — PHP определяет его на основании присвоенного значения.

Типы данных PHP делятся на несколько категорий.

### 1. Скалярные типы (Scalar Types)

Скалярные типы представляют отдельные значения.

|Тип|Описание|Пример|
|---|---|---|
|`int`|Целое число|`25`|
|`float`|Число с плавающей точкой|`10.5`|
|`string`|Строка|`'Hello'`|
|`bool`|Логическое значение|`true`, `false`|

### 2. Составные типы (Compound Types)

Составные типы позволяют хранить более сложные структуры данных.

**Array:**

```
<?php

$numbers = [1, 2, 3, 4];

$user = [
    'name' => 'John',
    'age' => 25,
];
```

**Object:**

```
<?php

class User
{
    public string $name = 'John';
}

$user = new User();

echo $user->name;
```

### 3. Специальные типы (Special Types)

|Тип|Описание|
|---|---|
|`null`|Отсутствие значения|
|`resource`|Внешний ресурс, например файловый дескриптор|
|`callable`|Значение, которое можно вызвать как функцию|

Также существует псевдотип `iterable`, обозначающий массив или объект, реализующий `Traversable`.

### Проверка типа данных

PHP предоставляет функции для проверки типа переменной.

```
<?php

$value = 100;

var_dump($value);

echo gettype($value);

var_dump(is_int($value));

var_dump(is_string($value));

var_dump(is_array($value));

var_dump(is_null($value));
```

### Преобразование типов (Type Casting)

Type Casting — явное преобразование одного типа данных в другой.

```
<?php

$number = '123';

$integer = (int) $number;

$float = (float) $number;

$string = (string) $integer;

$boolean = (bool) $number;
```

Другие варианты:

```
<?php

(array) $value;
(object) $value;
```

### Особенность Float Precision

Числа с плавающей точкой не всегда могут точно представлять десятичные дроби.

```
<?php

$result = 0.1 + 0.2;

var_dump($result);
```

Результат может отличаться от математически ожидаемого `0.3` из-за особенностей представления чисел в двоичной системе.

> [!warning] Денежные вычисления  
> Для финансовых операций не рекомендуется полагаться на прямые вычисления с `float`. Лучше хранить денежные значения в минимальных единицах валюты (например, центах) или использовать специализированную decimal-арифметику.

### Вопросы на собеседовании

**1. Какие типы данных существуют в PHP?**

PHP поддерживает скалярные типы `int`, `float`, `string`, `bool`; составные типы `array`, `object`, `callable`, `iterable`; а также специальные типы `null` и `resource`.

**2. Что означает динамическая типизация PHP?**

Тип переменной определяется автоматически на основании присвоенного значения. Одной и той же переменной можно присваивать значения разных типов.

**3. Чем отличаются int и float?**

`int` хранит целые числа, а `float` — числа с дробной частью. При работе с `float` возможны ошибки точности.

**4. Что такое null?**

`null` — специальное значение, обозначающее отсутствие значения. Переменная, которой присвоен `null`, имеет тип `null`.

**5. Как проверить тип переменной?**

Можно использовать `gettype()`, `var_dump()` или специализированные функции: `is_int()`, `is_string()`, `is_array()` и другие.

## 5. Система типов и Type Juggling

### Теория

PHP поддерживает два основных способа преобразования типов:

- **Implicit Type Conversion** — автоматическое преобразование.
    
- **Explicit Type Casting** — явное преобразование с помощью разработчика.
    

**Type Juggling** — механизм автоматического преобразования типов PHP при выполнении операций.

### Автоматическое преобразование типов

```
<?php

$result = '10' + 5;

var_dump($result); // int(15)
```

В данном случае PHP преобразует строку `'10'` в число.

Другой пример:

```
<?php

$value = 10;

$result = $value . ' apples';

echo $result; // 10 apples
```

При конкатенации целое число преобразуется в строку.

### Loose Comparison и Strict Comparison

Это одна из наиболее важных тем на PHP-собеседованиях.

**Loose Comparison (**`**==**`**)**

Сравнивает значения, предварительно выполняя преобразование типов, если оно необходимо.

**Strict Comparison (**`**===**`**)**

Сравнивает одновременно значение и тип данных без преобразования типов.

```
<?php

var_dump(5 == '5');  // true

var_dump(5 === '5'); // false
```

### Таблица сравнений

|Выражение|Результат|
|---|---|
|`5 == '5'`|true|
|`5 === '5'`|false|
|`5 != '5'`|false|
|`5 !== '5'`|true|
|`true == 1`|true|
|`null == false`|true|
|`null === false`|false|

### Преобразование в Boolean

Некоторые значения PHP автоматически интерпретирует как `false`:

- `false`
    
- `0`
    
- `0.0`
    
- `''` — пустая строка.
    
- `'0'` — строка с нулём.
    
- `[]` — пустой массив.
    
- `null`
    

Большинство остальных значений интерпретируется как `true`.

```
<?php

var_dump((bool) 0);       // false

var_dump((bool) '0');     // false

var_dump((bool) '');      // false

var_dump((bool) '0.0');   // true

var_dump((bool) []);      // false

var_dump((bool) 'false'); // true
```

> [!warning] Важный нюанс  
> Строка `'false'` является `true`, потому что это непустая строка. Аналогично строка `'0.0'` также является `true`.

### Strict Types

PHP поддерживает строгую проверку скалярных типов с помощью директивы:

```
declare(strict_types=1);
```

Пример:

```
<?php

declare(strict_types=1);

function sum(int $a, int $b): int
{
    return $a + $b;
}

echo sum(10, 20);
```

При включённом strict typing PHP строже проверяет соответствие скалярных аргументов и возвращаемых значений объявленным типам.

Без strict typing PHP может автоматически преобразовывать скалярные значения.

```
<?php

function calculate(int $number): int
{
    return $number;
}

echo calculate('10'); // 10 в режиме coercive typing
```

`strict_types` должен располагаться в начале файла после открывающего PHP-тега.

### Вопросы на собеседовании

**1. Что такое Type Juggling?**

Это механизм автоматического преобразования типов в PHP. Он используется при выполнении операций и передаче аргументов в функции, если допускается нестрогая типизация.

**2. Чем отличаются == и ===?**

`==` сравнивает значения с возможным преобразованием типов. `===` сравнивает и значение, и тип без преобразования.

**3. Почему рекомендуется использовать === вместо ==?**

Строгое сравнение позволяет избежать неожиданных результатов из-за автоматического преобразования типов и делает поведение программы более предсказуемым.

**4. Для чего используется strict_types=1?**

Он включает строгую проверку скалярных типов для вызовов, выполняемых из файла, в котором объявлена эта директива. Это уменьшает количество неявных преобразований типов.

**5. Считается ли строка '0' значением false?**

Да. В PHP строка `'0'` является одним из исключений: при преобразовании в Boolean она становится `false`.

**6. Считается ли строка 'false' значением false?**

Нет. Любая непустая строка, кроме `'0'`, преобразуется в `true`.

## 6. Операторы (Operators)

### Теория

**Операторы** — специальные символы или конструкции языка, которые позволяют выполнять операции над переменными и значениями.

PHP поддерживает несколько категорий операторов.

### Арифметические операторы

|Оператор|Назначение|Пример|
|---|---|---|
|`+`|Сложение|`$a + $b`|
|`-`|Вычитание|`$a - $b`|
|`*`|Умножение|`$a * $b`|
|`/`|Деление|`$a / $b`|
|`%`|Остаток от деления|`$a % $b`|
|`**`|Возведение в степень|`$a ** $b`|

```
<?php

$a = 10;
$b = 3;

echo $a + $b; // 13

echo $a % $b; // 1

echo $a ** 2; // 100
```

### Операторы присваивания

```
<?php

$x = 10;

$x += 5; // 15

$x -= 2; // 13

$x *= 2; // 26

$x /= 2; // 13

$x %= 5; // 3
```

### Операторы сравнения

```
<?php

$a = 10;
$b = 20;

var_dump($a == $b);

var_dump($a != $b);

var_dump($a < $b);

var_dump($a > $b);

var_dump($a <= $b);

var_dump($a >= $b);

var_dump($a === $b);

var_dump($a !== $b);
```

### Логические операторы

|Оператор|Назначение|
|---|---|
|`&&`|Логическое И|
|`||`|Логическое ИЛИ|
|`!`|Логическое НЕ|
|`and`|Логическое И|
|`or`|Логическое ИЛИ|
|`xor`|Исключающее ИЛИ|

```
<?php

$age = 25;
$hasLicense = true;

if ($age >= 18 && $hasLicense) {
    echo 'Can drive';
}
```

`&&` и `||` поддерживают короткое замыкание (Short-circuit Evaluation).

Например, если первая часть выражения с `&&` равна `false`, вторая часть уже не вычисляется.

### Операторы строк

Для объединения строк PHP использует оператор `.`.

```
<?php

$firstName = 'John';
$lastName = 'Smith';

$fullName = $firstName . ' ' . $lastName;

echo $fullName;
```

Оператор `.=` добавляет строку к существующей строке.

```
<?php

$message = 'Hello';

$message .= ' World';

echo $message;
```

### Null Coalescing Operator (??)

Оператор `??` возвращает левое значение, если оно существует и не равно `null`. В противном случае возвращается правое значение.

```
<?php

$username = $_GET['username'] ?? 'Guest';

echo $username;
```

Особенно полезен при работе с необязательными значениями.

### Null Coalescing Assignment (??=)

Оператор `??=` присваивает значение только тогда, когда переменная не определена или равна `null`.

```
<?php

$config = [];

$config['timezone'] ??= 'UTC';

echo $config['timezone'];
```

### Тернарный оператор (Ternary Operator)

Тернарный оператор — сокращённая форма простого условного выражения.

```
<?php

$age = 20;

$status = $age >= 18 ? 'Adult' : 'Minor';
```

### Spaceship Operator (<=>)

Оператор сравнивает два значения и возвращает:

- `-1`, если левое значение меньше.
    
- `0`, если значения равны.
    
- `1`, если левое значение больше.
    

```
<?php

var_dump(5 <=> 10);  // -1

var_dump(10 <=> 10); // 0

var_dump(15 <=> 10); // 1
```

Часто применяется в функциях сортировки.

### Match Expression

`match` появился в PHP 8.0.

В отличие от `switch`, он:

- Использует строгое сравнение `===`.
    
- Возвращает значение.
    
- Не допускает обычного fall-through.
    
- Не требует `break`.
    

```
<?php

$status = 200;

$message = match ($status) {
    200 => 'Success',
    404 => 'Not Found',
    500 => 'Server Error',
    default => 'Unknown Status',
};

echo $message;
```

### Вопросы на собеседовании

**1. Чем отличаются && и &?**

`&&` — логический оператор И, который работает с условиями и поддерживает короткое замыкание.

`&` — побитовый оператор И, который выполняет операцию над отдельными битами чисел. Он также может применяться к Boolean, но не имеет поведения короткого замыкания.

**2. Чем отличаются ?? и ?:?**

`??` проверяет, существует ли значение и не равно ли оно `null`.

`?:` проверяет, является ли значение истинным с точки зрения Boolean.

```
<?php

$value = 0;

$result1 = $value ?? 10; // 0

$result2 = $value ?: 10; // 10
```

**3. Что такое Spaceship Operator?**

Это оператор `<=>`, который сравнивает два значения и возвращает `-1`, `0` или `1`.

**4. Чем отличаются match и switch?**

`match` использует строгое сравнение, возвращает значение и не допускает fall-through. `switch` использует нестрогое сравнение и допускает переход к следующим case без `break`.

**5. Что такое Short-circuit Evaluation?**

Это механизм, при котором PHP прекращает вычисление логического выражения, когда результат уже известен.

Например, в `false && someFunction()` функция не будет вызвана.

## 7. Условные конструкции (Conditional Statements)

### Теория

Условные конструкции позволяют выполнять разные блоки кода в зависимости от результата проверки условия.

PHP предоставляет следующие конструкции:

- `if`
    
- `elseif`
    
- `else`
    
- `switch`
    
- `match`
    

### If

```
<?php

$age = 20;

if ($age >= 18) {
    echo 'Adult';
}
```

Код внутри блока выполняется только тогда, когда условие истинно.

### If / Else

```
<?php

$age = 16;

if ($age >= 18) {
    echo 'Adult';
} else {
    echo 'Minor';
}
```

### If / Elseif / Else

```
<?php

$score = 85;

if ($score >= 90) {
    echo 'Excellent';
} elseif ($score >= 70) {
    echo 'Good';
} elseif ($score >= 50) {
    echo 'Average';
} else {
    echo 'Fail';
}
```

PHP последовательно проверяет условия и выполняет первый подходящий блок.

### Switch

`switch` используется, когда необходимо сравнить одно выражение с несколькими возможными значениями.

```
<?php

$status = 'pending';

switch ($status) {
    case 'pending':
        echo 'Waiting for processing';
        break;

    case 'approved':
        echo 'Approved';
        break;

    case 'rejected':
        echo 'Rejected';
        break;

    default:
        echo 'Unknown status';
}
```

`break` останавливает выполнение `switch` и предотвращает переход к следующему `case`.

### Match

```
<?php

$status = 'approved';

$message = match ($status) {
    'pending' => 'Waiting',
    'approved' => 'Approved',
    'rejected' => 'Rejected',
    default => 'Unknown',
};
```

### Вопросы на собеседовании

**1. Чем отличаются if и switch?**

`if` подходит для сложных логических условий, диапазонов и комбинаций проверок. `switch` удобен, когда одно выражение нужно сравнить с несколькими значениями.

**2. Что произойдёт, если не использовать break в switch?**

PHP продолжит выполнять следующие блоки `case`, пока не встретит `break` или не завершится весь `switch`. Это называется fall-through.

**3. Чем отличаются switch и match?**

`switch` использует нестрогое сравнение и допускает fall-through. `match` использует строгое сравнение, возвращает значение и не требует `break`.

## 8. Циклы (Loops)

### Теория

**Циклы** позволяют многократно выполнять определённый блок кода, пока выполняется условие или пока не закончится перебор коллекции.

В PHP существует четыре основных вида циклов:

- `for`
    
- `while`
    
- `do...while`
    
- `foreach`
    

### For Loop

Цикл `for` обычно используется, когда количество итераций известно заранее.

Синтаксис:

```
for (initialization; condition; increment) {
    // Code
}
```

Пример:

```
<?php

for ($i = 0; $i < 5; $i++) {
    echo $i . PHP_EOL;
}
```

Результат:

```
0
1
2
3
4
```

### While Loop

Цикл `while` выполняется, пока условие остаётся истинным.

```
<?php

$i = 0;

while ($i < 5) {
    echo $i . PHP_EOL;

    $i++;
}
```

Условие проверяется перед каждой итерацией.

### Do While Loop

`do...while` сначала выполняет тело цикла, а затем проверяет условие.

Поэтому он гарантированно выполнится хотя бы один раз.

```
<?php

$i = 0;

do {
    echo $i;

    $i++;
} while ($i < 5);
```

### Foreach Loop

`foreach` предназначен для перебора массивов и других итерируемых значений.

```
<?php

$users = ['John', 'Alex', 'Michael'];

foreach ($users as $user) {
    echo $user . PHP_EOL;
}
```

Получение ключей и значений:

```
<?php

$user = [
    'name' => 'John',
    'age' => 25,
    'city' => 'London',
];

foreach ($user as $key => $value) {
    echo "$key: $value" . PHP_EOL;
}
```

### Break и Continue

`break` полностью завершает выполнение цикла.

```
<?php

for ($i = 0; $i < 10; $i++) {
    if ($i === 5) {
        break;
    }

    echo $i;
}
```

`continue` пропускает текущую итерацию и переходит к следующей.

```
<?php

for ($i = 0; $i < 5; $i++) {
    if ($i === 2) {
        continue;
    }

    echo $i;
}
```

### Foreach по ссылке

PHP позволяет перебирать элементы массива по ссылке.

```
<?php

$numbers = [1, 2, 3];

foreach ($numbers as &$number) {
    $number *= 2;
}

unset($number);

print_r($numbers);
```

Результат:

```
Array
(
    [0] => 2
    [1] => 4
    [2] => 6
)
```

> [!warning] Важный нюанс  
> После `foreach` с `&` рекомендуется выполнять `unset($number)`. Иначе переменная останется ссылкой на последний элемент массива и может привести к неожиданному изменению данных.

### Вопросы на собеседовании

**1. Чем отличаются while и do...while?**

`while` проверяет условие до выполнения тела цикла. Если условие изначально ложно, цикл не выполнится ни разу.

`do...while` проверяет условие после выполнения тела, поэтому гарантированно выполняется хотя бы один раз.

**2. Чем отличаются break и continue?**

`break` полностью прекращает цикл. `continue` пропускает текущую итерацию и переходит к следующей.

**3. Почему foreach удобен для работы с массивами?**

Он позволяет перебирать элементы массива без ручного управления индексами и делает код более читаемым.

**4. Что происходит при использовании & в foreach?**

Переменная цикла становится ссылкой на текущий элемент массива. Изменение этой переменной приводит к изменению исходного массива.

## 9. Функции (Functions)

### Теория

**Функция** — это переиспользуемый блок кода, предназначенный для выполнения определённой задачи.

Функции позволяют:

- Избегать дублирования кода.
    
- Разделять программу на логические части.
    
- Улучшать читаемость.
    
- Упрощать тестирование.
    
- Разделять ответственность между компонентами.
    

В PHP существуют встроенные и пользовательские функции.

### Объявление функции

```
<?php

function sayHello(): void
{
    echo 'Hello!';
}

sayHello();
```

Ключевое слово `function` используется для объявления функции.

Параметры указываются внутри круглых скобок, а тело функции — внутри фигурных.

### Параметры и аргументы

**Параметр (Parameter)** — переменная, объявленная в определении функции.

**Аргумент (Argument)** — конкретное значение, передаваемое при вызове функции.

```
<?php

function greet(string $name): void
{
    echo "Hello, $name!";
}

greet('John');
```

Здесь:

- `$name` — параметр.
    
- `'John'` — аргумент.
    

### Возвращаемое значение (Return Value)

Функция может возвращать результат с помощью `return`.

```
<?php

function sum(int $a, int $b): int
{
    return $a + $b;
}

$result = sum(10, 20);

echo $result;
```

Тип `int` после двоеточия указывает, что функция должна возвращать целое число.

### Void Return Type

`void` означает, что функция не возвращает значение.

```
<?php

function logMessage(string $message): void
{
    echo $message;
}
```

Функция с типом `void` может использовать `return;` без значения для досрочного завершения.

### Параметры по умолчанию (Default Parameters)

Параметрам можно назначать значения по умолчанию.

```
<?php

function greet(string $name = 'Guest'): string
{
    return "Hello, $name!";
}

echo greet();

echo greet('John');
```

Необязательные параметры обычно размещают после обязательных.

### Именованные аргументы (Named Arguments)

В PHP 8.0 появились именованные аргументы.

```
<?php

function createUser(
    string $name,
    int $age,
    string $city
): void {
    echo "$name, $age, $city";
}

createUser(
    name: 'John',
    city: 'London',
    age: 25
);
```

Это позволяет передавать аргументы по имени, а не только по позиции.

### Variadic Functions

Variadic Function — функция, принимающая переменное количество аргументов.

Для этого используется оператор `...`.

```
<?php

function sum(int ...$numbers): int
{
    return array_sum($numbers);
}

echo sum(1, 2, 3, 4);
```

PHP собирает переданные аргументы в массив `$numbers`.

### Передача по ссылке (Pass by Reference)

Обычно PHP передаёт аргументы по значению.

Чтобы функция могла изменить исходную переменную, используется `&`.

```
<?php

function increment(int &$number): void
{
    $number++;
}

$value = 10;

increment($value);

echo $value; // 11
```

### Анонимные функции (Anonymous Functions)

Анонимная функция — функция без собственного имени.

Её можно сохранить в переменную или передать в качестве callback.

```
<?php

$greet = function (string $name): string {
    return "Hello, $name";
};

echo $greet('John');
```

### Arrow Functions

Arrow Functions появились в PHP 7.4.

Они предоставляют сокращённый синтаксис для простых функций и автоматически захватывают внешние переменные по значению.

```
<?php

$multiplier = 2;

$double = fn(int $number): int => $number * $multiplier;

echo $double(5); // 10
```

В отличие от обычных анонимных функций, Arrow Functions автоматически захватывают внешние переменные по значению.

Они предназначены для одного выражения, а не для нескольких инструкций.

### First-Class Callable Syntax

В PHP 8.1 появился First-Class Callable Syntax.

Он позволяет создавать `Closure` на основе существующей функции или метода.

```
<?php

function double(int $number): int
{
    return $number * 2;
}

$callback = double(...);

echo $callback(5); // 10
```

### Callback Functions

Callback — это функция, которая передаётся в другую функцию в качестве аргумента.

```
<?php

$numbers = [1, 2, 3, 4];

$result = array_map(
    fn(int $number): int => $number * 2,
    $numbers
);

print_r($result);
```

Результат:

```
Array
(
    [0] => 2
    [1] => 4
    [2] => 6
    [3] => 8
)
```

### Вопросы на собеседовании

**1. Что такое функция в PHP?**

Функция — это переиспользуемый блок кода, выполняющий определённую задачу. Она может принимать параметры, выполнять операции и возвращать результат.

**2. Чем отличаются Parameter и Argument?**

Parameter — параметр, объявленный в определении функции. Argument — фактическое значение, переданное при вызове.

**3. Чем отличаются return и echo?**

`return` возвращает значение вызывающему коду и завершает выполнение функции. `echo` выводит информацию и не возвращает значение.

**4. Что такое Variadic Function?**

Это функция, которая может принимать переменное количество аргументов с помощью оператора `...`. Все переданные аргументы собираются в массив.

**5. Чем отличаются Anonymous Function и Arrow Function?**

Anonymous Function — функция без имени, которая может захватывать внешние переменные через `use`.

Arrow Function имеет более короткий синтаксис и автоматически захватывает внешние переменные по значению.

**6. Что такое Callback?**

Callback — это функция, передаваемая в другую функцию в качестве аргумента. Например, callback используется в `array_map()` и `array_filter()`.

**7. Чем отличается передача по значению от передачи по ссылке?**

При передаче по значению функция получает значение независимо от исходной переменной с точки зрения вызывающего кода.

При передаче по ссылке функция получает доступ к исходной переменной и может изменить её непосредственно.

## 10. Область видимости переменных (Variable Scope)

### Теория

**Variable Scope** определяет, в какой части программы можно обращаться к определённой переменной.

В PHP существуют следующие виды области видимости:

- Local Scope.
    
- Global Scope.
    
- Static Local Scope.
    
- Superglobal Scope.
    

### Local Scope

Переменная, объявленная внутри функции, имеет локальную область видимости.

```
<?php

function test(): void
{
    $name = 'John';

    echo $name;
}

test();

// echo $name; // Undefined variable
```

Переменная `$name` недоступна за пределами функции.

### Global Scope

Переменная, объявленная вне функции, принадлежит глобальной области видимости.

Однако глобальные переменные автоматически не становятся доступными внутри функций.

Для доступа можно использовать ключевое слово `global`.

```
<?php

$name = 'John';

function greet(): void
{
    global $name;

    echo $name;
}

greet();
```

Другой способ — массив `$GLOBALS`.

```
<?php

$name = 'John';

function greet(): void
{
    echo $GLOBALS['name'];
}

greet();
```

Глобальные переменные следует использовать осторожно, поскольку они создают скрытые зависимости и усложняют тестирование.

### Static Local Variables

Локальная статическая переменная сохраняет своё значение между вызовами функции в рамках одного контекста выполнения.

```
<?php

function counter(): int
{
    static $count = 0;

    return ++$count;
}

echo counter(); // 1

echo counter(); // 2

echo counter(); // 3
```

В отличие от обычной локальной переменной, статическая не инициализируется заново при каждом вызове функции.

В традиционной конфигурации PHP-FPM такая переменная не сохраняет состояние между независимыми HTTP-запросами.

### Superglobals

Superglobals — это предопределённые переменные PHP, доступные из любой области видимости.

|Переменная|Назначение|
|---|---|
|`$_GET`|Параметры URL|
|`$_POST`|Данные POST-запросов|
|`$_SERVER`|Информация о сервере и запросе|
|`$_COOKIE`|Cookies|
|`$_SESSION`|Данные сессии|
|`$_FILES`|Загруженные файлы|
|`$_REQUEST`|Объединённые данные запроса|
|`$_ENV`|Переменные окружения|
|`$GLOBALS`|Глобальные переменные|

Пример:

```
<?php

$username = $_GET['username'] ?? 'Guest';

echo htmlspecialchars($username);
```

### Вопросы на собеседовании

**1. Что такое Variable Scope?**

Это область программы, в которой переменная доступна. В PHP существуют локальная, глобальная, статическая локальная и суперглобальная области видимости.

**2. Можно ли использовать глобальную переменную внутри функции?**

Да. Для этого можно использовать `global` или массив `$GLOBALS`. Однако передача зависимостей через параметры обычно является более правильным архитектурным решением.

**3. Чем отличаются Local и Static Variables?**

Обычная локальная переменная существует во время выполнения функции и обычно уничтожается после её завершения.

Статическая локальная переменная сохраняет своё значение между вызовами функции в рамках одного контекста выполнения.

**4. Что такое Superglobals?**

Это предопределённые переменные PHP, доступные во всех областях видимости. Они позволяют получать информацию о запросах, сессиях, cookies, сервере и других данных.

## 11. Ссылки (References)

### Теория

**Reference** — механизм PHP, позволяющий нескольким переменным обращаться к одному и тому же значению переменной.

Для создания ссылки используется оператор `&`.

Важно понимать, что ссылки в PHP не являются указателями в том смысле, в котором они используются в C или C++. PHP не предоставляет через них прямой доступ к адресам памяти.

### Пример ссылки

```
<?php

$a = 10;

$b = &$a;

$b = 20;

echo $a; // 20

echo $b; // 20
```

Обе переменные обращаются к одному и тому же значению.

### Передача по ссылке

Функция может изменить исходную переменную, если параметр передаётся по ссылке.

```
<?php

function updateValue(int &$value): void
{
    $value = 100;
}

$number = 10;

updateValue($number);

echo $number; // 100
```

### Возврат по ссылке

PHP также поддерживает возвращение ссылок из функций, хотя в современной прикладной разработке это используется редко.

```
<?php

function &getValue(): mixed
{
    static $value = 10;

    return $value;
}

$number = &getValue();

$number = 50;
```

### Особенность объектов

Переменные объектов в PHP работают иначе, чем простые скалярные переменные.

При присваивании объекта другой переменной обе переменные ссылаются на одну и ту же идентичность объекта.

```
<?php

class User
{
    public string $name = 'John';
}

$user1 = new User();

$user2 = $user1;

$user2->name = 'Alex';

echo $user1->name; // Alex
```

Для этого не требуется явно использовать `&`.

### Вопросы на собеседовании

**1. Что такое Reference в PHP?**

Это механизм, позволяющий нескольким переменным обращаться к одному и тому же значению. Изменение значения через одну переменную отражается на другой.

**2. Чем отличается передача по значению от передачи по ссылке?**

При передаче по значению функция получает независимое с точки зрения вызывающего кода значение. При передаче по ссылке функция может непосредственно изменять исходную переменную.

**3. Нужно ли использовать ссылки для изменения свойств объектов?**

Нет. При присваивании объектной переменной другой переменной обе обращаются к одному объекту. Поэтому изменение его свойств через любую из переменных отражается на том же объекте.

## 12. Обработка ошибок (Error Handling)

### Теория

**Error Handling** — это процесс обнаружения, обработки и управления ошибками, возникающими во время выполнения программы.

PHP предоставляет несколько механизмов обработки ошибок.

Основные категории:

|Тип|Описание|
|---|---|
|Notice|Информационная ошибка, обычно не останавливает выполнение|
|Warning|Предупреждение, которое обычно не прекращает выполнение|
|Fatal Error|Критическая ошибка, при которой выполнение не может продолжаться|
|Parse Error|Синтаксическая ошибка, из-за которой код не может быть разобран|
|Exception|Объект, представляющий исключительную ситуацию|
|Error|Объект, представляющий ошибку PHP на уровне языка или выполнения|

В современном PHP `Error` и `Exception` реализуют общий интерфейс `Throwable`.

### Try и Catch

Блок `try` содержит код, который может выбросить исключение.

Блок `catch` обрабатывает возникшее исключение.

```
<?php

try {
    throw new Exception('Something went wrong');
} catch (Exception $exception) {
    echo $exception->getMessage();
}
```

### Finally

Блок `finally` выполняется после обработки конструкции `try/catch` независимо от того, было ли выброшено исключение, при условии нормального завершения потока выполнения.

```
<?php

try {
    echo 'Executing';
} catch (Exception $exception) {
    echo $exception->getMessage();
} finally {
    echo 'Cleanup';
}
```

Часто используется для операций очистки ресурсов.

### Выбрасывание исключений (Throwing Exceptions)

Разработчик может самостоятельно выбрасывать исключения с помощью `throw`.

```
<?php

function divide(int $a, int $b): float
{
    if ($b === 0) {
        throw new InvalidArgumentException(
            'Division by zero is not allowed'
        );
    }

    return $a / $b;
}

try {
    echo divide(10, 0);
} catch (InvalidArgumentException $exception) {
    echo $exception->getMessage();
}
```

### Иерархия исключений

В PHP существуют две основные ветви под интерфейсом `Throwable`:

```
Throwable
├── Error
│   ├── TypeError
│   ├── ParseError
│   └── ...
│
└── Exception
    ├── RuntimeException
    ├── InvalidArgumentException
    ├── LogicException
    └── ...
```

`catch (Throwable $exception)` позволяет перехватывать как `Error`, так и `Exception`.

### Пользовательские исключения (Custom Exceptions)

Разработчик может создавать собственные классы исключений.

```
<?php

class UserNotFoundException extends RuntimeException
{
}

function findUser(int $id): array
{
    if ($id <= 0) {
        throw new UserNotFoundException('User not found');
    }

    return [
        'id' => $id,
        'name' => 'John',
    ];
}

try {
    $user = findUser(0);
} catch (UserNotFoundException $exception) {
    echo $exception->getMessage();
}
```

Пользовательские исключения позволяют различать разные сценарии ошибок приложения.

### Настройки отображения ошибок

Во время разработки ошибки должны отображаться и записываться в логи.

Настройки для Development:

```
display_errors = On
log_errors = On
error_reporting = E_ALL
```

Настройки для Production:

```
display_errors = Off
log_errors = On
error_reporting = E_ALL
```

В production-среде ошибки рекомендуется записывать в логи, а не показывать пользователям.

Это предотвращает утечку внутренней информации приложения.

### Разница между Error и Exception

`Exception` обычно представляет исключительную ситуацию на уровне приложения, которую разработчик может явно обработать.

`Error` представляет проблему на уровне PHP или выполнения программы, например ошибку типов.

Оба типа реализуют интерфейс `Throwable`.

### Вопросы на собеседовании

**1. Чем отличаются Error и Exception в PHP?**

Оба реализуют интерфейс `Throwable`.

`Exception` обычно используется для представления исключительных ситуаций на уровне приложения.

`Error` представляет ошибки на уровне языка или выполнения PHP, например TypeError.

Оба типа можно перехватить через `catch (Throwable $e)`.

**2. Для чего нужны try, catch и finally?**

`try` содержит код, который может выбросить исключение.

`catch` обрабатывает возникшее исключение.

`finally` содержит код, который должен выполниться после конструкции try/catch, независимо от того, возникло исключение или нет.

**3. Можно ли создавать собственные исключения?**

Да. Для этого создаются собственные классы, которые наследуются от `Exception` или специализированных классов, например `RuntimeException`.

**4. Что такое Throwable?**

`Throwable` — общий интерфейс, который реализуют `Error` и `Exception`. Благодаря ему можно перехватывать оба типа ошибок одним блоком `catch`.

**5. Нужно ли показывать ошибки пользователям в Production?**

Нет. В production следует отключать отображение ошибок и включать логирование. Это предотвращает раскрытие конфиденциальной информации приложения.

**6. Чем отличаются Warning и Exception?**

Warning — это диагностическое сообщение PHP, которое само по себе не является объектом исключения.

Exception — объект, который можно явно выбросить через `throw` и обработать через `catch`.

При необходимости обычные ошибки PHP можно преобразовывать в исключения с помощью пользовательского обработчика ошибок.

# Итоги Part 1 — Основы PHP

## Что необходимо знать перед переходом к следующей части

- PHP — динамически типизированный серверный язык программирования.

- Переменные начинаются со знака `$`.

- При присваивании объектных переменных обе переменные обращаются к одной идентичности объекта.
    
- `Throwable` — общий интерфейс для `Error` и `Exception`.
    
- В Production ошибки следует записывать в логи, а не показывать пользователям.
