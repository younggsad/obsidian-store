# 10 — ООП. Наследование, полиморфизм, инкапсуляция и абстракция

## 1. Теория

### Четыре столпа ООП
1. **Инкапсуляция**: Сокрытие внутреннего состояния и реализации объекта, предоставление публичного интерфейса для взаимодействия (`public` методы, сеттеры/геттеры).
2. **Наследование**: Механизм, позволяющий одному классу (потомок / subclass) переиспользовать код и структуру другого класса (родитель / superclass) с помощью ключевого слова `extends`. В PHP поддерживается **только одиночное наследование классов**.
3. **Полиморфизм**: Способность объектов с одинаковым интерфейсом обрабатывать данные различным образом (через переопределение методов — Method Overriding и динамическую диспетчеризацию).
4. **Абстракция**: Выделение ключевых характеристик объекта и отсечение второстепенных деталей с помощью абстрактных классов (`abstract class`).

---

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

abstract class PaymentProcessor {
    // Абстрактный метод (обязателен к реализации в наследниках)
    abstract public function charge(float $amount): bool;

    public function logTransaction(float $amount): void {
        echo "Processing payment of {$amount}\n";
    }
}

class StripeProcessor extends PaymentProcessor {
    public function charge(float $amount): bool {
        $this->logTransaction($amount);
        // Логика Stripe API
        return true;
    }
}

$processor = new StripeProcessor();
$processor->charge(100.0);
```

## 3. Вопросы на собеседовании

1. **Почему в PHP поддерживается только одиночное наследование классов?**
   *Ответ*: Чтобы избежать проблемы множественного наследования (так называемой «проблемы ромба» / Diamond Problem), когда класс-потомок не может однозначно определить, какой из родительских методов выполнять. Для решения этой задачи в PHP используются Traits и Interfaces.
2. **В чем разница между переопределением методов (Method Overriding) и перегрузкой (Method Overloading)?**
   *Ответ*: Переопределение — это замена реализации родительского метода в классе-потомке. Перегрузка (создание нескольких методов с одинаковым именем, но разными аргументами) в классическом виде PHP не поддерживается напрямую, но реализуется через магические методы (`__call`, `__callStatic`).
3. **Может ли абстрактный класс содержать неабстрактные методы?**
   *Ответ*: Да. Абстрактный класс может содержать как абстрактные методы (без тела, обязательные для реализации), так и полностью рабочие методы с реализацией.
