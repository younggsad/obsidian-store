## 1. Фундаментальная теория и архитектура

### Четыре столпа ООП
1. **Инкапсуляция**: Сокрытие реализации, защита состояния через модификаторы доступа и интерфейсы.
2. **Наследование**: Механизм `extends`. В PHP поддерживается **исключительно одиночное наследование классов** для предотвращения «проблемы ромба» (Diamond Problem).
3. **Полиморфизм**: Способность работать с объектами разных классов через общий интерфейс благодаря динамической диспетчеризации методов.
4. **Абстракция**: Создание базовых шаблонов через `abstract class`.

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

abstract class Notifier {
    abstract public function send(string $recipient, string $message): void;

    public function log(string $message): void {
        echo "[LOG]: " . $message . "\n";
    }
}

class EmailNotifier extends Notifier {
    public function send(string $recipient, string $message): void {
        $this->log("Sending email to {$recipient}");
        // Реализация отправки email
    }
}
```

## 3. Детальные вопросы на техническом собеседовании

1. **Почему в PHP запрещено множественное наследование классов?**
   *Ответ*: Чтобы исключить проблему неоднозначности методов (Diamond Problem), возникающую, когда два родительских класса содержат методы с одинаковыми именами. PHP заменяет множественное наследование классов комбинацией интерфейсов и трейтов.
2. **В чем разница между переопределением (Overriding) и перегрузкой (Overloading)?**
   *Ответ*: Переопределение — изменение реализации родительского метода в классе-потомке с сохранением сигнатуры. Перегрузка (создание нескольких методов с одинаковым именем, но разными типами/количеством аргументов) в классическом виде в PHP не поддерживается, но эмулируется через магические методы (`__call`).
3. **Может ли абстрактный класс содержать конструктор?**
   *Ответ*: Да, абстрактный класс может иметь конструктор, который будет вызываться при инстанцировании класса-последника через `parent::__construct()`.
4. **Что такое LSP (Liskov Substitution Principle) и как его нарушают?**
   *Ответ*: Подклассы должны быть заменяемыми для базовых классов без нарушения работы программы. Нарушается, например, если потомок выбрасывает неожиданные исключения или сужает требования к входным аргументам (что противоречит контрвариантности параметров в PHP).
