# PHP Interview Preparation — Part 1: PHP Fundamentals

## 1. Introduction to PHP

### Theory

**PHP (PHP: Hypertext Preprocessor)** is an open-source, general-purpose scripting language primarily used for server-side web development.

PHP executes on the server. The server processes PHP code and sends the generated result to the client, usually as HTML or JSON.

PHP is commonly used for:

- Dynamic websites.
    
- REST APIs.
    
- Backend applications.
    
- Content Management Systems (Drupal, WordPress).
    
- E-commerce platforms.
    
- CLI scripts and automation.
    
- Background jobs and scheduled tasks.
    

### How PHP works

A typical PHP request follows this flow:

1. A client sends an HTTP request.
    
2. The web server (Nginx or Apache) receives it.
    
3. The request is passed to PHP through PHP-FPM (in a typical Nginx setup).
    
4. PHP executes the application code.
    
5. The application may communicate with a database or external services.
    
6. PHP generates a response.
    
7. The web server sends the response to the client.
    

### PHP execution model

PHP is generally request-based in traditional PHP-FPM deployments.

Each HTTP request is handled by a PHP worker. PHP executes the application code and finishes the request. PHP-FPM workers can be reused for subsequent requests, but ordinary request-scoped application state does not automatically persist between requests.

### PHP versions

Important modern PHP features:

|Version|Important features|
|---|---|
|PHP 7.0|Scalar type declarations, return types, null coalescing operator|
|PHP 7.4|Typed properties, arrow functions|
|PHP 8.0|Union types, named arguments, attributes, match, constructor property promotion|
|PHP 8.1|Enums, readonly properties, fibers, intersection types|
|PHP 8.2|Readonly classes, DNF types, deprecated dynamic properties|
|PHP 8.3|Typed class constants, dynamic class constant fetch|
|PHP 8.4|Property hooks, asymmetric visibility, property access improvements|

### Code Example

```
<?php

$name = 'John';

echo "Hello, {$name}!";
```

Output:

```
Hello, John!
```

A simple PHP file can generate HTML:

```
<?php

$title = 'My Website';

?>

<!DOCTYPE html>
<html>
<head>
    <title><?= htmlspecialchars($title) ?></title>
</head>
<body>
    <h1>Welcome to my website</h1>
</body>
</html>
```

The `<?=` syntax is a shorthand for `echo`.

### Interview Questions & Answers

**Q1. What is PHP?**

PHP is a server-side scripting language mainly used for web development. It executes on the server and generates responses such as HTML or JSON, which are sent to the client.

**Q2. Is PHP compiled or interpreted?**

PHP source code is compiled into Zend Engine opcodes, which are then executed by the Zend VM. Therefore, PHP is often described as an interpreted language, but internally it uses a compilation step.

**Q3. What is the difference between client-side and server-side languages?**

Client-side code executes in the user's browser. JavaScript is a common example.

Server-side code executes on the server. PHP is an example. It can access databases, process requests, implement business logic and generate responses.

**Q4. What happens when a user opens a PHP page?**

The browser sends an HTTP request. The web server passes the PHP request to the PHP runtime, typically through PHP-FPM. PHP executes the application, generates a response and returns it through the web server to the browser.

**Q5. Is PHP suitable for REST API development?**

Yes. PHP can process HTTP requests, validate data, execute business logic, communicate with databases and return JSON responses. Frameworks such as Symfony and Laravel provide tools for building REST APIs.

## 2. PHP Syntax and Basic Structure

### Theory

PHP code is written inside PHP opening and closing tags.

```
<?php

// PHP code

?>
```

The opening tag `<?php` tells the interpreter that PHP code begins.

The closing tag `?>` is optional in files containing only PHP code. It is generally recommended to omit it in PHP-only files to avoid accidental whitespace output.

### Statements

A statement is an instruction executed by PHP.

Most PHP statements end with a semicolon (`;`).

```
<?php

$name = 'John';
$age = 25;

echo $name;
echo $age;
```

### Comments

PHP supports three types of comments.

**Single-line comments:**

```
// This is a comment

# This is also a comment
```

**Multi-line comments:**

```
/*
This is a
multi-line comment
*/
```

**Documentation comments (PHPDoc):**

```
/**
 * Calculates the total price.
 *
 * @param float $price
 * @param int $quantity
 * @return float
 */
function calculateTotal(float $price, int $quantity): float
{
    return $price * $quantity;
}
```

PHPDoc is useful for IDE support, static analysis and documenting complex APIs.

### Output

PHP provides several ways to output information.

```
<?php

echo 'Hello';
print 'World';

var_dump(123);
print_r(['apple', 'banana']);
```

|Function|Purpose|
|---|---|
|`echo`|Outputs one or more strings|
|`print`|Outputs a string and returns 1|
|`var_dump()`|Displays type and value|
|`print_r()`|Displays human-readable information|

### Case Sensitivity

PHP has some case-sensitive and some case-insensitive elements.

- Variable names are case-sensitive.
    
- Function names are generally case-insensitive.
    
- Class names are generally case-insensitive at the language level, but PSR-4 autoloading and filesystem conventions require consistent casing.
    
- Keywords are case-insensitive.
    

```
<?php

$name = 'John';

// Different variables:
$Name = 'Alex';

echo $name; // John
echo $Name; // Alex
```

### Interview Questions & Answers

**Q1. What is the purpose of PHP opening and closing tags?**

They identify where PHP code begins and ends inside a file. The closing tag can be omitted in PHP-only files to prevent accidental output caused by whitespace.

**Q2. What is the difference between echo and print?**

Both output information. `echo` can output multiple arguments and does not return a value. `print` accepts one argument and returns 1.

**Q3. What is the difference between var_dump() and print_r()?**

`var_dump()` displays the data type and value, while `print_r()` focuses on readable representation of values, especially arrays and objects.

**Q4. Are PHP variables case-sensitive?**

Yes. `$name` and `$Name` are different variables.

## 3. Variables and Constants

### Theory

A variable stores data that can be accessed and modified during program execution.

In PHP, variable names begin with the dollar sign (`$`).

### Variable naming rules

- Must begin with `$`.
    
- The first character after `$` must be a letter or underscore.
    
- Cannot begin with a number.
    
- Can contain letters, numbers and underscores.
    
- Variable names are case-sensitive.
    

```
<?php

$name = 'John';
$age = 25;
$user_name = 'john_doe';

// Invalid examples:
// $2name = 'John';
// $user-name = 'John';
```

### Variable assignment

PHP uses the assignment operator `=`.

```
<?php

$number = 10;
$number = 20;

echo $number; // 20
```

The value can be changed during execution.

### Constants

A constant stores a value that cannot be reassigned after definition.

There are two common ways to define constants.

**Using define():**

```
<?php

define('APP_NAME', 'My Application');

echo APP_NAME;
```

**Using const:**

```
<?php

const APP_VERSION = '1.0.0';

echo APP_VERSION;
```

### Difference between const and define()

|Feature|const|define()|
|---|---|---|
|Definition|Language construct|Function|
|Declaration|Compile-time|Runtime|
|Global constants|Yes|Yes|
|Conditional declaration|Not directly|Yes|
|Class constants|Yes|No|
|Namespaced constants|Yes|Yes|

Example of conditional definition:

```
<?php

if (!defined('APP_ENV')) {
    define('APP_ENV', 'production');
}
```

### Class Constants

Constants can also belong to classes.

```
<?php

class Database
{
    public const HOST = 'localhost';
    public const PORT = 3306;
}

echo Database::HOST;
```

Modern PHP also supports typed class constants from PHP 8.3.

```
<?php

class Config
{
    public const string ENVIRONMENT = 'production';
}
```

### Variable Variables

PHP supports variable variables. They allow the name of a variable to be determined dynamically.

```
<?php

$name = 'username';

$$name = 'John';

echo $username; // John
```

Here, `$$name` creates a variable named `$username`.

This feature is rarely necessary in modern application code.

### Interview Questions & Answers

**Q1. What is the difference between a variable and a constant?**

A variable can be reassigned during execution, while a constant cannot be redefined after its value has been established.

**Q2. What is the difference between const and define()?**

`const` is a language construct evaluated at compile time, while `define()` is a runtime function. `define()` can be used conditionally, whereas `const` cannot be declared inside a conditional block.

**Q3. Can a constant be changed?**

No. A constant cannot be reassigned after definition.

**Q4. What are variable variables?**

Variable variables allow the name of a variable to be determined dynamically using another variable. They are supported by PHP but should be used carefully because they can make code harder to understand.

## 4. Data Types

### Theory

PHP is a dynamically typed language. A variable does not need an explicit type declaration, and its type is determined by the value assigned to it.

PHP has several built-in data types.

### Scalar Types

Scalar types represent single values.

|Type|Description|Example|
|---|---|---|
|`int`|Integer numbers|`25`|
|`float`|Floating-point numbers|`10.5`|
|`string`|Text|`'Hello'`|
|`bool`|Boolean value|`true`, `false`|

### Compound Types

Compound types can contain multiple values or structures.

**Array:**

```
<?php

$numbers = [1, 2, 3, 4];

$users = [
    'name' => 'John',
    'age' => 25,
];
```

**Object:**

```
<?php

class User
{
    public string $name = 'John';
}

$user = new User();

echo $user->name;
```

### Special Types

|Type|Description|
|---|---|
|`null`|Represents the absence of a value|
|`resource`|Represents an external resource, such as a file handle|
|`callable`|Represents something that can be called as a function|

### Checking Data Types

PHP provides several functions for checking types.

```
<?php

$value = 100;

var_dump($value);

echo gettype($value);

var_dump(is_int($value));
var_dump(is_string($value));
var_dump(is_array($value));
var_dump(is_null($value));
```

### Type Casting

Type casting converts a value from one type to another.

```
<?php

$number = '123';

$integer = (int) $number;
$float = (float) $number;
$string = (string) $integer;
$boolean = (bool) $number;
```

Other casting operators include:

- `(array)`
    
- `(object)`
    
- `(unset)` — removed in PHP 8.0.
    

### Important: Float Precision

Floating-point numbers cannot represent every decimal fraction exactly.

```
<?php

$result = 0.1 + 0.2;

var_dump($result);
```

The result may not be exactly `0.3`.

For financial calculations, avoid relying on direct floating-point equality. Use integer values in the smallest currency unit (for example, cents) or an appropriate decimal arithmetic solution.

### Interview Questions & Answers

**Q1. What data types does PHP support?**

PHP supports scalar types (`int`, `float`, `string`, `bool`), compound types (`array`, `object`, `callable`, `iterable`) and special types such as `null` and `resource`.

**Q2. Is PHP dynamically typed?**

Yes. PHP determines the type of a variable from its assigned value. A variable can hold different types during its lifetime unless stricter constraints are applied through type declarations.

**Q3. What is the difference between int and float?**

`int` represents whole numbers, while `float` represents numbers with fractional parts. Floating-point calculations may introduce precision errors.

**Q4. What is null?**

`null` represents the absence of a value. A variable explicitly assigned `null` has the null type.

**Q5. How can you check the type of a variable?**

Use `gettype()` to obtain a type name, `var_dump()` to inspect type and value, or specific functions such as `is_int()`, `is_string()` and `is_array()`.

## 5. Type System and Type Juggling

### Theory

PHP supports both implicit and explicit type conversion.

**Type juggling** is the automatic conversion of a value from one type to another when required by an operation.

### Implicit Type Conversion

PHP can automatically convert types in certain operations.

```
<?php

$result = '10' + 5;

var_dump($result); // int(15)
```

The numeric string `'10'` is converted into a number.

Another example:

```
<?php

$value = 10;

$result = $value . ' apples';

echo $result; // 10 apples
```

The concatenation operator converts the integer into a string.

### Loose Comparison vs Strict Comparison

One of the most important PHP interview topics is the difference between `==` and `===`.

**Loose comparison (**`**==**`**)**

Compares values after performing type conversion when necessary.

**Strict comparison (**`**===**`**)**

Compares both value and data type without type juggling.

```
<?php

var_dump(5 == '5');  // true

var_dump(5 === '5'); // false
```

### Comparison Table

|Expression|Result|
|---|---|
|`5 == '5'`|true|
|`5 === '5'`|false|
|`5 != '5'`|false|
|`5 !== '5'`|true|
|`true == 1`|true|
|`null == false`|true|
|`null === false`|false|

### Boolean Conversion

Values that evaluate to false include:

- `false`
    
- `0`
    
- `0.0`
    
- `''` (empty string)
    
- `'0'` (string containing zero)
    
- `[]` (empty array)
    
- `null`
    

Other values generally evaluate to true.

```
<?php

var_dump((bool) 0);    // false
var_dump((bool) '0');  // false
var_dump((bool) '');   // false
var_dump((bool) '0.0'); // true
var_dump((bool) []);   // false
var_dump((bool) 'false'); // true
```

Important: the string `'false'` is truthy because it is a non-empty string.

### Strict Types

PHP supports strict typing through the `declare(strict_types=1)` directive.

```
<?php

declare(strict_types=1);

function sum(int $a, int $b): int
{
    return $a + $b;
}

echo sum(10, 20);
```

With strict typing enabled, scalar type declarations are enforced more strictly for calls made from that file.

Without strict typing, PHP may perform scalar coercion:

```
<?php

function calculate(int $number): int
{
    return $number;
}

echo calculate('10'); // 10 in coercive mode
```

The `strict_types` declaration must be placed at the beginning of the file, apart from the opening PHP tag and permitted declaration-related syntax.

### Interview Questions & Answers

**Q1. What is type juggling?**

Type juggling is PHP's automatic conversion of values between data types during operations or function calls when scalar type coercion is permitted.

**Q2. What is the difference between == and ===?**

`==` compares values and may convert types before comparison. `===` compares both value and type without type conversion.

**Q3. Why should we prefer === over ==?**

Strict comparison avoids unexpected results caused by implicit type conversion. It makes comparisons more predictable and reduces bugs.

**Q4. What does strict_types=1 do?**

It enables strict scalar type checking for calls originating from the file where it is declared. It reduces implicit scalar type coercion but does not disable every form of PHP type conversion.

**Q5. Is the string '0' considered false in PHP?**

Yes. The string `'0'` is one of the special values PHP treats as false in boolean conversion.

**Q6. Is the string 'false' considered false?**

No. A non-empty string other than `'0'` is considered true.

## 6. Operators

### Theory

Operators are symbols or keywords used to perform operations on variables and values.

PHP provides several categories of operators.

### Arithmetic Operators

|Operator|Description|Example|
|---|---|---|
|`+`|Addition|`$a + $b`|
|`-`|Subtraction|`$a - $b`|
|`*`|Multiplication|`$a * $b`|
|`/`|Division|`$a / $b`|
|`%`|Modulus|`$a % $b`|
|`**`|Exponentiation|`$a ** $b`|

```
<?php

$a = 10;
$b = 3;

echo $a + $b; // 13
echo $a % $b; // 1
echo $a ** 2; // 100
```

### Assignment Operators

```
<?php

$x = 10;

$x += 5; // 15
$x -= 2; // 13
$x *= 2; // 26
$x /= 2; // 13
$x %= 5; // 3
```

### Comparison Operators

```
<?php

$a = 10;
$b = 20;

var_dump($a == $b);
var_dump($a != $b);
var_dump($a < $b);
var_dump($a > $b);
var_dump($a <= $b);
var_dump($a >= $b);
var_dump($a === $b);
var_dump($a !== $b);
```

### Logical Operators

|Operator|Meaning|
|---|---|
|`&&`|Logical AND|
|`||`|Logical OR|
|`!`|Logical NOT|
|`and`|Logical AND|
|`or`|Logical OR|
|`xor`|Exclusive OR|

```
<?php

$age = 25;
$hasLicense = true;

if ($age >= 18 && $hasLicense) {
    echo 'Can drive';
}
```

`&&` and `||` use short-circuit evaluation. For example, the second operand of `&&` is not evaluated if the first operand is false.

### String Operators

PHP uses `.` for string concatenation.

```
<?php

$firstName = 'John';
$lastName = 'Smith';

$fullName = $firstName . ' ' . $lastName;

echo $fullName;
```

The `.=` operator appends a string.

```
<?php

$message = 'Hello';

$message .= ' World';

echo $message;
```

### Null Coalescing Operator

The `??` operator returns the left operand if it exists and is not null. Otherwise, it returns the right operand.

```
<?php

$username = $_GET['username'] ?? 'Guest';

echo $username;
```

It is particularly useful when working with optional values.

### Null Coalescing Assignment

The `??=` operator assigns a value only if the variable is undefined or null.

```
<?php

$config = [];

$config['timezone'] ??= 'UTC';

echo $config['timezone'];
```

### Ternary Operator

The ternary operator is a shorthand for a simple conditional expression.

```
<?php

$age = 20;

$status = $age >= 18 ? 'Adult' : 'Minor';
```

### Spaceship Operator

The spaceship operator (`<=>`) compares two values.

It returns:

- `-1` if the left value is smaller.
    
- `0` if both values are equal.
    
- `1` if the left value is greater.
    

```
<?php

var_dump(5 <=> 10); // -1
var_dump(10 <=> 10); // 0
var_dump(15 <=> 10); // 1
```

It is often used in sorting callbacks.

### Match Expression

The `match` expression was introduced in PHP 8.0.

Unlike `switch`, it uses strict comparison (`===`), returns a value and does not require `break`.

```
<?php

$status = 200;

$message = match ($status) {
    200 => 'Success',
    404 => 'Not Found',
    500 => 'Server Error',
    default => 'Unknown Status',
};

echo $message;
```

### Interview Questions & Answers

**Q1. What is the difference between && and &?**

`&&` is a logical AND operator that evaluates boolean conditions and supports short-circuit evaluation. `&` is a bitwise AND operator that works on individual bits of integer values. It can also be used with booleans, but does not have the same short-circuit behavior.

**Q2. What is the difference between ?? and ?:?**

`??` checks whether the left operand is defined and not null. `?:` checks whether the left operand evaluates to true.

```
<?php

$value = 0;

$result1 = $value ?? 10; // 0
$result2 = $value ?: 10; // 10
```

**Q3. What is the spaceship operator?**

It compares two values and returns -1, 0 or 1 depending on whether the left operand is smaller, equal or greater.

**Q4. What is the difference between match and switch?**

`match` uses strict comparison, returns a value, does not fall through and does not require `break`. `switch` uses loose comparison and supports fall-through behavior.

**Q5. What is short-circuit evaluation?**

It means PHP stops evaluating a logical expression as soon as its result is determined. For example, if the first condition in `false && someFunction()` is false, the function is not executed.

## 7. Conditional Statements

### Theory

Conditional statements allow a program to execute different blocks of code depending on whether a condition is true or false.

PHP provides:

- `if`
    
- `elseif`
    
- `else`
    
- `switch`
    
- `match`
    

### If Statement

```
<?php

$age = 20;

if ($age >= 18) {
    echo 'Adult';
}
```

The code inside the block executes only when the condition evaluates to true.

### If / Else

```
<?php

$age = 16;

if ($age >= 18) {
    echo 'Adult';
} else {
    echo 'Minor';
}
```

### If / Elseif / Else

```
<?php

$score = 85;

if ($score >= 90) {
    echo 'Excellent';
} elseif ($score >= 70) {
    echo 'Good';
} elseif ($score >= 50) {
    echo 'Average';
} else {
    echo 'Fail';
}
```

PHP checks conditions sequentially and executes the first matching block.

### Switch Statement

`switch` is useful when one expression needs to be compared against multiple possible values.

```
<?php

$status = 'pending';

switch ($status) {
    case 'pending':
        echo 'Waiting for processing';
        break;

    case 'approved':
        echo 'Approved';
        break;

    case 'rejected':
        echo 'Rejected';
        break;

    default:
        echo 'Unknown status';
}
```

The `break` statement prevents execution from continuing into the next case.

### Match Expression

```
<?php

$status = 'approved';

$message = match ($status) {
    'pending' => 'Waiting',
    'approved' => 'Approved',
    'rejected' => 'Rejected',
    default => 'Unknown',
};
```

### Interview Questions & Answers

**Q1. What is the difference between if and switch?**

`if` is suitable for complex boolean conditions and ranges. `switch` is convenient when comparing one expression against multiple values.

**Q2. What happens if break is omitted in switch?**

Execution continues into subsequent cases until a break or the end of the switch statement is reached. This is called fall-through.

**Q3. What is the difference between switch and match?**

`switch` is a statement that uses loose comparisons and can fall through. `match` is an expression that uses strict comparisons and returns a value.

## 8. Loops

### Theory

Loops allow developers to execute a block of code repeatedly while a condition is satisfied or while iterating over a collection.

PHP provides four primary loop structures:

- `for`
    
- `while`
    
- `do...while`
    
- `foreach`
    

### For Loop

A `for` loop is useful when the number of iterations is known.

Syntax:

```
for (initialization; condition; increment) {
    // Code
}
```

Example:

```
<?php

for ($i = 0; $i < 5; $i++) {
    echo $i . PHP_EOL;
}
```

Output:

```
0
1
2
3
4
```

### While Loop

A `while` loop executes while the condition remains true.

```
<?php

$i = 0;

while ($i < 5) {
    echo $i . PHP_EOL;
    $i++;
}
```

The condition is checked before each iteration.

### Do While Loop

A `do...while` loop executes the code at least once because the condition is checked after the first iteration.

```
<?php

$i = 0;

do {
    echo $i;
    $i++;
} while ($i < 5);
```

### Foreach Loop

`foreach` is designed for iterating over arrays and other iterable values.

```
<?php

$users = ['John', 'Alex', 'Michael'];

foreach ($users as $user) {
    echo $user . PHP_EOL;
}
```

Accessing keys and values:

```
<?php

$user = [
    'name' => 'John',
    'age' => 25,
    'city' => 'London',
];

foreach ($user as $key => $value) {
    echo "$key: $value" . PHP_EOL;
}
```

### Break and Continue

`break` terminates the loop.

```
<?php

for ($i = 0; $i < 10; $i++) {
    if ($i === 5) {
        break;
    }

    echo $i;
}
```

`continue` skips the current iteration and proceeds to the next one.

```
<?php

for ($i = 0; $i < 5; $i++) {
    if ($i === 2) {
        continue;
    }

    echo $i;
}
```

### References in Foreach

PHP allows iteration by reference.

```
<?php

$numbers = [1, 2, 3];

foreach ($numbers as &$number) {
    $number *= 2;
}

unset($number);

print_r($numbers);
```

Result:

```
Array
(
    [0] => 2
    [1] => 4
    [2] => 6
)
```

Important: after a `foreach` by reference, unset the reference variable. Otherwise, it remains a reference to the last array element and can cause unexpected modifications.

### Interview Questions & Answers

**Q1. What is the difference between while and do...while?**

`while` checks the condition before execution, so its body might never execute. `do...while` checks the condition after execution, so the body always executes at least once.

**Q2. What is the difference between break and continue?**

`break` terminates the loop completely. `continue` skips the current iteration and moves to the next one.

**Q3. Why is foreach preferred for arrays?**

It provides a readable way to iterate over array elements without manually managing indexes.

**Q4. What happens when foreach uses &?**

The loop variable becomes a reference to the current array element, so changing the variable modifies the original array.

## 9. Functions

### Theory

A function is a reusable block of code that performs a specific task.

Functions help developers:

- Avoid code duplication.
    
- Organize application logic.
    
- Improve readability.
    
- Make code easier to test.
    
- Separate responsibilities.
    

PHP supports built-in functions and user-defined functions.

### Defining a Function

```
<?php

function sayHello(): void
{
    echo 'Hello!';
}

sayHello();
```

The `function` keyword defines a function.

The parentheses contain parameters, and the body contains the code to execute.

### Parameters and Arguments

A parameter is a variable declared in a function definition.

An argument is the actual value passed when calling the function.

```
<?php

function greet(string $name): void
{
    echo "Hello, $name!";
}

greet('John');
```

Here:

- `$name` is the parameter.
    
- `'John'` is the argument.
    

### Return Values

Functions can return values using the `return` statement.

```
<?php

function sum(int $a, int $b): int
{
    return $a + $b;
}

$result = sum(10, 20);

echo $result;
```

The return type `int` specifies that the function returns an integer.

### Void Return Type

`void` indicates that a function does not return a value.

```
<?php

function logMessage(string $message): void
{
    echo $message;
}
```

A void function can use `return;` without a value to exit early.

### Default Parameters

Parameters can have default values.

```
<?php

function greet(string $name = 'Guest'): string
{
    return "Hello, $name!";
}

echo greet();
echo greet('John');
```

Optional parameters should generally be placed after required parameters.

### Named Arguments

PHP 8.0 introduced named arguments.

```
<?php

function createUser(
    string $name,
    int $age,
    string $city
): void {
    echo "$name, $age, $city";
}

createUser(
    name: 'John',
    city: 'London',
    age: 25
);
```

Named arguments allow parameters to be passed by name rather than position.

### Variadic Functions

Variadic functions accept a variable number of arguments using `...`.

```
<?php

function sum(int ...$numbers): int
{
    return array_sum($numbers);
}

echo sum(1, 2, 3, 4);
```

The `...` operator collects arguments into an array.

### Passing Arguments by Reference

PHP normally passes arguments by value.

To modify the original variable, a function can accept it by reference using `&`.

```
<?php

function increment(int &$number): void
{
    $number++;
}

$value = 10;

increment($value);

echo $value; // 11
```

### Anonymous Functions

An anonymous function is a function without a declared name.

It can be assigned to a variable or passed as a callback.

```
<?php

$greet = function (string $name): string {
    return "Hello, $name";
};

echo $greet('John');
```

### Arrow Functions

Arrow functions were introduced in PHP 7.4.

They provide shorter syntax for simple functions and automatically capture outer variables by value.

```
<?php

$multiplier = 2;

$double = fn(int $number): int => $number * $multiplier;

echo $double(5); // 10
```

Unlike traditional closures, arrow functions automatically capture outer variables by value. They cannot contain multiple statements in their expression body.

### First-Class Callable Syntax

PHP 8.1 introduced first-class callable syntax.

It allows developers to create a Closure from an existing function or method.

```
<?php

function double(int $number): int
{
    return $number * 2;
}

$callback = double(...);

echo $callback(5); // 10
```

### Callback Functions

A callback is a function passed as an argument to another function.

```
<?php

$numbers = [1, 2, 3, 4];

$result = array_map(
    fn(int $number): int => $number * 2,
    $numbers
);

print_r($result);
```

Result:

```
Array
(
    [0] => 2
    [1] => 4
    [2] => 6
    [3] => 8
)
```

### Interview Questions & Answers

**Q1. What is a function in PHP?**

A function is a reusable block of code designed to perform a specific task. It can accept parameters, execute logic and optionally return a value.

**Q2. What is the difference between a parameter and an argument?**

A parameter is declared in the function definition. An argument is the actual value passed when calling the function.

**Q3. What is the difference between return and echo?**

`return` sends a value back to the caller and terminates the function. `echo` outputs information and does not return a value.

**Q4. What is a variadic function?**

A variadic function accepts a variable number of arguments using the `...` syntax. PHP collects those arguments into an array.

**Q5. What is the difference between an anonymous function and an arrow function?**

An anonymous function is a function without a name and can capture external variables using `use`. An arrow function has shorter syntax and automatically captures outer variables by value.

**Q6. What is a callback?**

A callback is a callable value passed to another function so that the receiving function can execute it. Common examples include callbacks passed to `array_map()` and `array_filter()`.

**Q7. What is the difference between passing by value and passing by reference?**

Passing by value means the function receives a value independently of the caller's variable. Passing by reference means the function can access and modify the original variable.

## 10. Variable Scope

### Theory

Variable scope defines where a variable can be accessed in a PHP application.

PHP has several types of scope:

- Local scope.
    
- Global scope.
    
- Static local scope.
    
- Superglobal scope.
    

### Local Scope

A variable declared inside a function is local to that function.

```
<?php

function test(): void
{
    $name = 'John';

    echo $name;
}

test();

// echo $name; // Undefined variable
```

The variable `$name` cannot be accessed outside the function.

### Global Scope

A variable declared outside a function belongs to the global scope.

However, global variables are not automatically accessible inside functions.

```
<?php

$name = 'John';

function greet(): void
{
    global $name;

    echo $name;
}

greet();
```

Another way is using `$GLOBALS`.

```
<?php

$name = 'John';

function greet(): void
{
    echo $GLOBALS['name'];
}

greet();
```

Global variables should be used carefully because they create hidden dependencies and make testing harder.

### Static Local Variables

A static local variable retains its value between function calls within the same request.

```
<?php

function counter(): int
{
    static $count = 0;

    return ++$count;
}

echo counter(); // 1
echo counter(); // 2
echo counter(); // 3
```

Unlike a regular local variable, the static variable is not reinitialized on every call.

It does not automatically persist across separate traditional PHP-FPM requests.

### Superglobals

Superglobals are predefined variables accessible from all scopes.

Important examples:

|Superglobal|Purpose|
|---|---|
|`$_GET`|Query string parameters|
|`$_POST`|Form data sent using POST|
|`$_SERVER`|Server and request information|
|`$_COOKIE`|Cookies|
|`$_SESSION`|Session data|
|`$_FILES`|Uploaded files|
|`$_REQUEST`|Combined request variables|
|`$_ENV`|Environment variables|
|`$GLOBALS`|Global variables|

Example:

```
<?php

$username = $_GET['username'] ?? 'Guest';

echo htmlspecialchars($username);
```

### Interview Questions & Answers

**Q1. What is variable scope?**

Variable scope defines where a variable can be accessed in a program. PHP supports local, global, static local and superglobal variables.

**Q2. Can you access a global variable inside a function?**

Yes. You can use the `global` keyword or access it through the `$GLOBALS` array. However, passing dependencies as function parameters is generally a cleaner approach.

**Q3. What is the difference between local and static variables?**

A local variable is created when the function executes and normally disappears when it finishes. A static local variable retains its value between function calls within the same execution context.

**Q4. What are superglobals?**

Superglobals are predefined PHP variables available in all scopes. They provide access to request data, sessions, cookies, server information and other global data.

## 11. References

### Theory

A reference in PHP allows two variables to refer to the same underlying variable value.

The `&` operator is used to create a reference.

References are different from pointers in languages such as C or C++. PHP does not expose raw memory addresses through its reference syntax.

### Basic Example

```
<?php

$a = 10;

$b = &$a;

$b = 20;

echo $a; // 20
echo $b; // 20
```

Both variables refer to the same value.

### Passing by Reference

A function can modify the original variable by accepting a parameter by reference.

```
<?php

function updateValue(int &$value): void
{
    $value = 100;
}

$number = 10;

updateValue($number);

echo $number; // 100
```

### Returning by Reference

PHP also supports returning references, although this is uncommon in application code.

```
<?php

function &getValue(): mixed
{
    static $value = 10;

    return $value;
}

$number = &getValue();

$number = 50;
```

### Important Difference: Objects

PHP object variables do not behave like simple scalar variables.

When an object variable is assigned to another variable, both variables refer to the same object identity.

```
<?php

class User
{
    public string $name = 'John';
}

$user1 = new User();
$user2 = $user1;

$user2->name = 'Alex';

echo $user1->name; // Alex
```

This happens without explicitly using `&`.

### Interview Questions & Answers

**Q1. What is a reference in PHP?**

A reference allows multiple variables to refer to the same underlying variable value. Modifying the value through one reference affects the other.

**Q2. What is the difference between passing by value and passing by reference?**

By value, a function receives an independent value from the caller's perspective. By reference, it can modify the caller's variable directly.

**Q3. Do objects require references to modify their properties?**

No. PHP object variables contain object handles. Assigning an object variable to another variable makes both variables refer to the same object identity, so modifying its properties through either variable affects the same object.

## 12. Error Handling

### Theory

Error handling is the process of detecting, reporting and managing problems that occur during program execution.

PHP provides different mechanisms for handling errors.

Important categories include:

|Category|Description|
|---|---|
|Notice|Informational issue; generally non-fatal|
|Warning|Problem that does not normally stop script execution|
|Fatal Error|Execution cannot continue|
|Parse Error|Syntax error preventing code from being parsed|
|Exception|An object representing an exceptional condition|
|Error|An object representing a PHP engine or runtime error|

In modern PHP, `Error` and `Exception` both implement the `Throwable` interface.

### Try and Catch

The `try` block contains code that may throw an exception.

The `catch` block handles the exception.

```
<?php

try {
    throw new Exception('Something went wrong');
} catch (Exception $exception) {
    echo $exception->getMessage();
}
```

### Finally

The `finally` block executes after the try/catch flow, regardless of whether an exception was thrown or caught, subject to normal control-flow termination.

```
<?php

try {
    echo 'Executing';
} catch (Exception $exception) {
    echo $exception->getMessage();
} finally {
    echo 'Cleanup';
}
```

It is commonly used for cleanup operations.

### Throwing Exceptions

Developers can throw exceptions manually.

```
<?php

function divide(int $a, int $b): float
{
    if ($b === 0) {
        throw new InvalidArgumentException(
            'Division by zero is not allowed'
        );
    }

    return $a / $b;
}

try {
    echo divide(10, 0);
} catch (InvalidArgumentException $exception) {
    echo $exception->getMessage();
}
```

### Exception Hierarchy

PHP has two major branches under `Throwable`:

```
Throwable
├── Error
│   ├── TypeError
│   ├── ParseError
│   └── ...
└── Exception
    ├── RuntimeException
    ├── InvalidArgumentException
    ├── LogicException
    └── ...
```

A `catch (Throwable $exception)` can catch both `Error` and `Exception` objects.

### Custom Exceptions

Developers can create their own exception classes.

```
<?php

class UserNotFoundException extends RuntimeException
{
}

function findUser(int $id): array
{
    if ($id <= 0) {
        throw new UserNotFoundException('User not found');
    }

    return ['id' => $id, 'name' => 'John'];
}

try {
    $user = findUser(0);
} catch (UserNotFoundException $exception) {
    echo $exception->getMessage();
}
```

Custom exceptions help distinguish different failure scenarios.

### Error Reporting

During development, PHP errors should be visible and logged.

Typical development settings:

```
display_errors = On
log_errors = On
error_reporting = E_ALL
```

Production settings:

```
display_errors = Off
log_errors = On
error_reporting = E_ALL
```

In production, errors should be logged rather than displayed to users because error messages can expose sensitive application information.

### Error vs Exception

An `Exception` usually represents a condition an application can explicitly handle.

An `Error` represents a problem at the PHP engine or language level, such as a type error.

Both implement `Throwable`.

### Interview Questions & Answers

**Q1. What is the difference between an Error and an Exception in PHP?**

Both implement `Throwable`. An `Exception` is generally used to represent application-level exceptional situations, while an `Error` represents problems related to PHP execution, such as type errors. Both can be caught with `catch (Throwable $e)`.

**Q2. What is the purpose of try, catch and finally?**

`try` contains code that may throw an exception. `catch` handles the thrown exception. `finally` contains cleanup logic that runs after the try/catch flow, regardless of whether an exception was thrown.

**Q3. Can we create custom exceptions?**

Yes. We can create custom exception classes by extending `Exception` or a more specific exception class such as `RuntimeException`.

**Q4. What is Throwable?**

`Throwable` is the common interface implemented by both `Error` and `Exception`. It allows both categories to be caught using one catch block.

**Q5. Should errors be displayed in production?**

No. Production applications should generally disable error display and enable error logging. This prevents sensitive information from being exposed to users.

**Q6. What is the difference between a warning and an exception?**

A warning is a PHP diagnostic error that is not automatically represented as an exception. An exception is a throwable object that can be explicitly thrown and caught. PHP error handling can convert certain errors into exceptions, but this requires an error handler.

- PHP is a dynamically typed server-side language.
