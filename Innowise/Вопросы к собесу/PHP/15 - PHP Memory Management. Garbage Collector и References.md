# 15 — PHP Memory Management. Garbage Collector и References

## 1. Теория

### Управление памятью в PHP
- **Reference Counting (Подсчет ссылок)**: Каждый контейнер переменной (zval) содержит счетчик ссылок. Когда переменная присваивается другой переменной или передается в функцию, счетчик увеличивается. Когда область видимости переменной заканчивается, счетчик уменьшается. Если счетчик равен 0, память освобождается.
- **Copy-on-Write (COW)**: Оптимизация памяти. При присвоении большой переменной (например, массива) другой переменной данные физически не дублируются. Обе переменные указывают на один участок памяти. Копирование происходит только тогда, когда одна из переменных начинает изменяться.

### Циклы ссылок и Сборщик мусора (Garbage Collector)
- Подсчет ссылок не справляется с циклическими зависимостями (например, объект A ссылается на объект B, а объект B на объект A). Когда такие переменные удаляются из области видимости, их счетчик ссылок падает до 1 (а не до 0).
- **Garbage Collector (GC)** периодически запускается, находит изолированные циклические структуры, помечает их, проверяет уменьшение счетчиков при условном обходе и очищает утечки.

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

// Демонстрация Copy-on-Write
$largeArray = range(1, 10000);
$refArray = $largeArray; // Память не дублируется (COW)

// Модификация приводит к физическому копированию памяти
$largeArray[0] = 999; 

// Управление сборщиком мусора
gc_enable(); // Включить GC
echo gc_enabled() ? "GC is active" : "GC is inactive";
gc_collect_cycles(); // Принудительный запуск сборщика
```

## 3. Вопросы на собеседовании

1. **Как работает механизм Copy-on-Write (COW) в PHP?**
   *Ответ*: Это механизм оптимизации памяти. При копировании переменных данные не дублируются в памяти сразу; переменные ссылаются на общий блок данных с инкрементированным счетчиком ссылок. Дублирование (копирование) происходит только в момент модификации одной из переменных.
2. **Какую проблему решает сборщик мусора (Garbage Collector) в дополнение к подсчету ссылок?**
   *Ответ*: Подсчет ссылок бесполезен при циклических ссылках (circular references), когда объекты ссылаются друг на друга, образуя замкнутый контур. Их счетчик ссылок никогда не падает до нуля при обычном выходе из области видимости. GC циклически сканирует такие структуры и очищает их.
3. **Что такое `zval` в PHP?**
   *Ответ*: `zval` (Zend Value) — это внутренняя структура данных в Zend Engine, представляющая любую переменную в PHP. Она хранит тип данных, само значение, а также флаги подсчета ссылок и признак того, является ли значение ссылкой.
