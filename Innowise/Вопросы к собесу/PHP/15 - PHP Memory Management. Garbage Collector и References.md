## 1. Фундаментальная теория и архитектура

### Управление памятью в Zend Engine
- **Reference Counting**: Каждая переменная (структура `zval`) хранит счетчик ссылок. Когда счетчик падает до 0, память освобождается.
- **Copy-on-Write (COW)**: Оптимизация памяти: переменные разделяют один блок данных до момента изменения одной из них.
- **Garbage Collector (GC)**: Циклический сборщик мусора, предназначенный для очистки циклических ссылок (когда объекты ссылаются друг на друга, и счетчик ссылок не падает до нуля).

---

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

// Демонстрация работы с циклами ссылок и сборщиком мусора
class Node {
    public ?Node $child = null;
}

$parent = new Node();
$child = new Node();
$parent->child = $child;
$child->child = $parent; // Циклическая ссылка

unset($parent, $child); // Счетчик ссылок останется равным 1
gc_collect_cycles(); // Сборщик мусора очистит память
```

## 3. Детальные вопросы на техническом собеседовании

1. **Что такое `zval` в контексте управления памятью PHP?**
   *Ответ*: `zval` (Zend Value) — это внутренняя структура данных в Zend Engine, представляющая любую переменную в PHP. Она содержит тип данных, само значение и служебные флаги (включая счетчик ссылок).
2. **Почему обычный подсчет ссылок не справляется с циклическими зависимостями?**
   *Ответ*: Если два объекта ссылаются друг на друга, то при удалении переменных из области видимости счетчик ссылок каждого из них уменьшается, но остается равным 1 (из-за ссылки друг на друга). Такие изолированные циклы очищает отдельный сборщик мусора (GC).
3. **Как работает Copy-on-Write для массивов и строк?**
   *Ответ*: При присвоении переменной данные не копируются физически — обе переменные указывают на один `zval` с увеличенным счетчиком ссылок. Физическое копирование происходит только в момент изменения одной из переменных.
4. **Как принудительно управлять сборщиком мусора в скрипте?**
   *Ответ*: С помощью функций `gc_enable()`, `gc_disable()` и `gc_collect_cycles()`, что актуально для долгоживущих CLI-скриптов и воркеров.
