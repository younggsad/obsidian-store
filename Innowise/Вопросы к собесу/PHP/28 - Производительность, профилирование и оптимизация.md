# 28 — Производительность, профилирование и оптимизация

## 1. Теория

### Профилирование (Profiling)
- Инструменты поиска узких мест (bottlenecks), утечек памяти и медленных SQL-запросов:
  - **Xdebug** / **Xdebug Profiler** (генерация кэшgrind-файлов для анализа в KCacheGrind / Webgrind).
  - **Blackfire.io** — профессиональный SaaS-профайлер для PHP.
  - **XHProf** / **Tideways** — легковесные профайлеры для production.

### Оптимизация производительности
1. Включение и тонкая настройка **OPcache**.
2. Использование кэширования (Redis, Memcached, APCu).
3. Оптимизация запросов к базе данных (индексы, избежание проблемы N+1).
4. Микрооптимизации кода (минимизация тяжелых вызовов внутри циклов, использование генераторов).

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

// Измерение времени выполнения и потребления памяти
$startMemory = memory_get_usage(true);
$startTime = microtime(true);

// Тяжелая операция
$data = range(1, 100000);

$endTime = microtime(true);
$endMemory = memory_get_usage(true);

printf(
    "Execution time: %.4f sec\nMemory consumed: %d KB",
    $endTime - $startTime,
    ($endMemory - $startMemory) / 1024
);
```

## 3. Вопросы на собеседовании

1. **Что такое проблема N+1 в базах данных и как ее решать?**
   *Ответ*: Возникает, когда для получения списка записей делается 1 запрос, а затем для каждой записи в цикле делается еще по 1 дополнительному запросу (всего $N+1$). Решение: использование жадной загрузки (Eager Loading через `JOIN` или `with()` в ORM).
2. **Какие инструменты используются для профилирования PHP-приложений на production?**
   *Ответ*: Blackfire.io, Tideways или XHProf. Они имеют минимальные накладные расходы и позволяют построить граф вызовов функций с указанием времени выполнения и потребления памяти.
3. **Как OPcache влияет на производительность PHP?**
   *Ответ*: OPcache компилирует PHP-скрипты в байт-код один раз и сохраняет его в разделяемой памяти. Без OPcache PHP тратит процессорное время на чтение, лексический анализ и компиляцию каждого файла при каждом входящем HTTP-запросе.
