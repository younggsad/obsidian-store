# 06 — Массивы и работа с коллекциями

## 1. Теория

### Устройство массивов в PHP
В PHP массив — это на самом деле упорядоченная хэш-таблица (Ordered Hash Table). Каждому элементу соответствует ключ (`int` или `string`) и значение (`mixed`). Это одновременно и список, и хеш-мапа, и стек, и очередь.

### Виды массивов
1. **Индицированные (Indexed)**: Ключи — числовые индексы (автоматически с 0).
2. **Ассоциативные (Associative)**: Ключи задаются явно строками.
3. **Многомерные (Multidimensional)**: Массивы внутри массивов.

### Полезные функции для работы с массивами
- **Поиск и проверка**: `in_array()`, `array_key_exists()`, `isset()`, `array_search()`.
- **Фильтрация и проекция**: `array_map()`, `array_filter()`, `array_reduce()`.
- **Преобразования**: `array_merge()` vs оператор распаковки `[...$arr1, ...$arr2]`, `array_keys()`, `array_values()`, `array_flip()`.
- **Сортировка**: `sort()`, `asort()`, `ksort()`, `usort()`.

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

$users = [
    ['id' => 1, 'name' => 'Alice', 'active' => true],
    ['id' => 2, 'name' => 'Bob', 'active' => false],
    ['id' => 3, 'name' => 'Charlie', 'active' => true],
];

// Фильтрация и отображение (Functional approach)
$activeNames = array_map(
    fn($user) => $user['name'],
    array_filter($users, fn($user) => $user['active'])
);

// Слияние массивов через оператор распаковки (PHP 7.4+)
$array1 = ['a' => 1, 'b' => 2];
$array2 = ['b' => 99, 'c' => 3];
$merged = [...$array1, ...$array2]; // Значение 'b' перезапишется на 99
```

## 3. Вопросы на собеседовании

1. **Как устроены массивы под капотом в PHP?**
   *Ответ*: Массивы PHP реализованы как упорядоченные хэш-таблицы (Ordered Hash Tables). Они поддерживают как последовательную индексацию, так и произвольные ключи, сохраняя порядок добавления элементов.
2. **В чем разница между `array_merge()` и оператором распаковки `[...$arr1, ...$arr2]`?**
   *Ответ*: `array_merge()` переиндексирует числовые ключи заново, а строковые ключи перезаписывает. Оператор распаковки (`[...]`) для числовых ключей также переиндексирует, но для строковых ключей ведет себя аналогично с перезаписью последних.
3. **Чем отличаются `isset()` и `array_key_exists()` при проверке ключа в массиве?**
   *Ответ*: `array_key_exists()` проверяет наличие ключа независимо от того, каково его значение. `isset()` проверяет существование ключа и то, что его значение **не равно `null`**.
4. **Как работает обход массива через `foreach` под капотом?**
   *Ответ*: Внутренний указатель массива перемещается во время итераций. В современном PHP у массивов есть механизм Copy-on-Write, предотвращающий лишнее копирование памяти при чтении.
