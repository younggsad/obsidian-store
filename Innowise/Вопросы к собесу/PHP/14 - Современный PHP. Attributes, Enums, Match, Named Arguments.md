## 1. Фундаментальная теория и архитектура

### Современные возможности PHP 8.x
1. **Attributes (Атрибуты)**: Нативные метаданные (`#[Route('/api')]`), проверяемые парсером и читаемые через Reflection API.
2. **Enums (Перечисления)**: Чистые и скалярные (Backed) перечисления с поддержкой методов и интерфейсов.
3. **Match Expression**: Строгое сопоставление с паттернами.
4. **First-Class Callable Syntax**: Получение ссылки на метод в виде объекта `Closure` через `...`.

---

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

enum HttpStatus: int {
    case OK = 200;
    case NotFound = 404;

    public function message(): string {
        return match($this) {
            self::OK => 'OK',
            self::NotFound => 'Not Found',
        };
    }
}
```

## 3. Детальные вопросы на техническом собеседовании

1. **В чем преимущества нативных Enums перед старыми константами классов?**
   *Ответ*: Нативные перечисления гарантируют строгую типизацию (аргумент метода может принимать только конкретный Enum), поддерживают методы, интерфейсы и встроенные методы сериализации `from()` / `tryFrom()`.
2. **Как работают PHP Attributes и почему они эффективнее `@Annotation` в DocBlocks?**
   *Ответ*: Атрибуты проверяются синтаксическим анализатором Zend Engine на этапе компиляции, исключая орфографические ошибки. DocBlocks — это просто текстовые комментарии, требующие тяжеловесного парсинга в рантайме.
3. **Что такое First-Class Callable Syntax (`strlen(...)`)?**
   *Ответ*: Это нативный способ создания объекта `Closure` для функции или метода без использования потенциально небезопасных строк-коллбэков (`'strlen'`). Поддерживается IDE и статическими анализаторами.
4. **Какие типы поддерживают скалярные перечисления (Backed Enums)?**
   *Ответ*: Только `string` и `int`.
