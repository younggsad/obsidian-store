# 14 — Современный PHP. Attributes, Enums, Match, Named Arguments

## 1. Теория

### Ключевые возможности современного PHP (8.0 - 8.3)
1. **Attributes (Атрибуты / Аннотации)**: Нативная замена Doctrine/PHPDoc аннотациям в виде метаданных (`#[Route('/api')]`), обрабатываемых через Reflection API.
2. **Enums (Перечисления)**: Нативная поддержка перечислений. Бывают:
   - Чистые (Pure Enums) — просто набор кейсов.
   - Скалярные (Backed Enums) — привязанные к значению (`string` или `int`), поддерживают методы и интерфейсы.
3. **Match Expression**: Строгое сопоставление с образцом (рассмотрено ранее).
4. **Named Arguments (Именованные аргументы)**: Передача аргументов по имени параметров (рассмотрено ранее).
5. **First-Class Callable Syntax (`...`)**: Способ получения ссылки на метод или функцию в виде объекта `Closure` (например, `$fn = strlen(...)`).

---

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

// Enums (Backed Enum)
enum Role: string {
    case Admin = 'admin';
    case User = 'user';

    public function label(): string {
        return match($this) {
            self::Admin => 'Administrator',
            self::User => 'Standard User',
        };
    }
}

// Attributes
#[Attribute]
class AuditLog {
    public function __construct(public string $action) {}
}

class OrderService {
    #[AuditLog(action: 'create_order')]
    public function checkout(): void {}
}
```

## 3. Вопросы на собеседовании

1. **В чем преимущества нативных Enums перед старыми константами или классами-константами?**
   *Ответ*: Нативные Enums обеспечивают строгую типизацию, гарантируют, что передаваемое значение принадлежит только данному набору, поддерживают методы, интерфейсы и имеют встроенный метод `from()` / `tryFrom()` для сериализации/десериализации.
2. **Как работают PHP Attributes и чем они лучше докблоков (`@Annotation`)?**
   *Ответ*: Атрибуты — это структурированный нативный код, проверяемый на этапе компиляции (синтаксис валидируется Zend Engine). Докблоки — это всего лишь текстовые комментарии, которые парсятся сторонними библиотеками в рантайме с накладными расходами.
3. **Что такое First-Class Callable Syntax и для чего он нужен?**
   *Ответ*: Синтаксис `strlen(...)` позволяет получить объект `Closure` для существующей функции или метода. Это безопасная замена старым строковым коллбэкам (`'strlen'`), поддерживаемая статическими анализаторами.
