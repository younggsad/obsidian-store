# 18 — Работа с файлами, потоками и сериализацией

## 1. Теория

### Файловая система
- Базовые функции: `file_get_contents()`, `file_put_contents()`, `file_exists()`, `is_readable()`.
- Для безопасного чтения и записи больших файлов лучше использовать низкоуровневые функции работы с дескрипторами: `fopen()`, `fread()`, `fwrite()`, `fclose()`.

### Потоки (Streams) и Stream Wrappers
- Потоки в PHP унифицируют доступ к файлам, сети, сокетам и сжатым данным через универсальные обертки (например, `http://`, `php://input`, `php://memory`, `zip://`).

### Сериализация данных
- `serialize()` / `unserialize()` — стандартная сериализация PHP в байтовую строку (уязвима при десериализации небезопасных данных).
- `json_encode()` / `json_decode()` — сериализация в формат JSON (рекомендуемый стандарт для API).

---

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

// Чтение тела входящего HTTP-запроса через поток php://input
$rawInput = file_get_contents('php://input');
$data = json_decode($rawInput, true);

// Безопасная запись в файл с блокировкой
file_put_contents('log.txt', date('Y-m-d H:i:s') . " - Event\n", FILE_APPEND | LOCK_EX);
```

## 3. Вопросы на собеседовании

1. **Что такое `php://input` и когда он используется?**
   *Ответ*: Это поток для чтения сырых данных (raw data) из тела входящего HTTP-запроса. Незаменим при обработке REST API запросов в формате JSON, когда данные не передаются через стандартные суперглобальные массивы `$_POST`.
2. **Какие риски безопасности связаны с функцией `unserialize()`?**
   *Ответ*: Если десериализовать данные, полученные от пользователя, злоумышленник может внедрить специально сформированную строку, которая вызовет уязвимость PHP Object Injection и исполнит произвольный код через магические методы (`__wakeup`, `__destruct`).
3. **Что делает флаг `LOCK_EX` в функции `file_put_contents()`?**
   *Ответ*: Устанавливает эксклюзивную блокировку файла на время записи, предотвращая состояние гонки (race condition), если несколько процессов пытаются записать данные в один файл одновременно.
