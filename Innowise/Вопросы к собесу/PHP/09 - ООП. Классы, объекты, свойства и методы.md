## 1. Фундаментальная теория и архитектура

### Классы, объекты и инстанциация
- **Класс**: Шаблон, описывающий структуру (свойства) и поведение (методы). В памяти компилируется в структуру `zend_class_entry`.
- **Объект**: Экземпляр класса. Создается через оператор `new`, выделяет память в куче (heap) через Zend Memory Manager.
- **Модификаторы видимости**: `public`, `protected`, `private`. Проверяются как во время компиляции, так и в рантайме.
- **Constructor Property Promotion**: Синтаксический сахар PHP 8 для одновременного объявления и инициализации свойств в конструкторе.

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

class UserAccount {
    public function __construct(
        public readonly int $id,
        public string $username,
        private string $passwordHash
    ) {}

    public function verifyPassword(string $password): bool {
        return password_verify($password, $this->passwordHash);
    }
}
```

## 3. Детальные вопросы на техническом собеседовании

1. **Как объекты хранятся и передаются в памяти PHP?**
   *Ответ*: Объекты хранятся в куче. В переменных содержится дескриптор (указатель) на объект. Присвоение переменной, содержащей объект, копирует только этот дескриптор (указатель), а не сам объект в памяти.
2. **Что такое Constructor Property Promotion и как это обрабатывается компилятором?**
   *Ответ*: Это синтаксический сахар, который во время парсинга преобразуется компилятором в стандартное объявление свойств и их инициализацию в конструкторе.
3. **В чем разница между видимостью `protected` и `private` в контексте наследования?**
   *Ответ*: `protected` свойства и методы доступны как в самом классе, так и во всех его классах-потомках. `private` элементы доступны строго внутри класса-родителя; наследники не имеют к ним доступа и могут переопределять имена с теми же названиями, создавая независимые свойства.
4. **Что происходит при уничтожении объекта (`__destruct`)?**
   *Ответ*: Деструктор вызывается автоматически, когда на объект больше не остается ни одной ссылки в скрипте (счетчик ссылок zval равен нулю) или при завершении работы скрипта.
