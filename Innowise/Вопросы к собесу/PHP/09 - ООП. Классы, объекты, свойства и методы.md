# 09 — ООП. Классы, объекты, свойства и методы

## 1. Теория

### Основы ООП в PHP
PHP поддерживает полноценное объектно-ориентированное программирование начиная с PHP 5 и значительно расширив возможности в PHP 7 и 8.
- **Класс**: Шаблон (чертеж) для создания объектов, определяющий свойства (state) и методы (behavior).
- **Объект**: Экземпляр класса. Создается с помощью ключевого слова `new`.
- **Конструктор и деструктор**:
  - `__construct()` — инициализирует объект при создании.
  - `__destruct()` — вызывается, когда на объект больше не остается ссылок или скрипт завершает работу.
- **Модификаторы видимости (Visibility)**:
  - `public`: Доступно отовсюду.
  - `protected`: Доступно внутри класса и его наследников.
  - `private`: Доступно только внутри текущего класса.
- **Constructor Property Promotion (PHP 8.0+)**: Синтаксический сахар для автоматического объявления свойств класса прямо в сигнатуре конструктора.

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

class User {
    // Constructor Property Promotion (PHP 8+)
    public function __construct(
        public readonly int $id,
        public string $name,
        private string $email
    ) {}

    public function getEmail(): string {
        return $this->email;
    }
}

$user = new User(1, 'Alice', 'alice@example.com');
echo $user->name; // Alice
```

## 3. Вопросы на собеседовании

1. **Что такое Constructor Property Promotion и какие преимущества она дает?**
   *Ответ*: Позволяет объявлять свойства класса и инициализировать их прямо в сигнатуре конструктора (`public function __construct(public string $name)`). Это избавляет от дублирования кода и уменьшает бойлерплейт.
2. **В чем разница между `protected` и `private` модификаторами?**
   *Ответ*: Свойства и методы со спецификатором `protected` видны в текущем классе и всех классах-потомках. `private` ограничивает видимость строго рамками того класса, в котором они объявлены (даже наследники не имеют к ним прямого доступа).
3. **Как объекты передаются и присваиваются в PHP?**
   *Ответ*: Объекты в PHP всегда присваиваются и передаются по идентификатору (ссылке на объект в памяти), а не копируются целиком по значению (в отличие от скалярных типов или массивов до копирования).
