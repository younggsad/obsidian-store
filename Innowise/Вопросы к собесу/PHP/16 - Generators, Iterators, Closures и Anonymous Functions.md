## 1. Фундаментальная теория и архитектура

### Генераторы (`yield`)
- Позволяют реализовать ленивые вычисления (Lazy evaluation). Функция возвращает итератор, выдающий элементы по одному, не загружая весь объем данных в оперативную память.

### Итераторы и SPL
- Интерфейс `Iterator` позволяет объектам контролировать поведение в циклах `foreach`.

### Замыкания и стрелочные функции
- `Closure` объекты. Стрелочные функции (`fn($x) => $x + $y`) захватывают внешние переменные автоматически по значению.

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

// Эффективный генератор для чтения больших логов
function readLogFile(string $path): \Generator {
    $handle = fopen($path, 'r');
    try {
        while (($line = fgets($handle)) !== false) {
            yield trim($line);
        }
    } finally {
        fclose($handle);
    }
}
```

## 3. Детальные вопросы на техническом собеседовании

1. **В чем главное преимущество генераторов перед возвратом больших массивов?**
   *Ответ*: Генераторы расходуют минимальное количество памяти ($O(1)$), так как не хранят всю коллекцию в оперативной памяти, а вычисляют и возвращают элементы по одному с помощью `yield`.
2. **Как работает механизм захвата переменных в стрелочных функциях (Arrow Functions)?**
   *Ответ*: Стрелочные функции автоматически захватывают переменные из внешней области видимости **по значению** (by-value). Изменить внешнюю скалярную переменную внутри стрелочной функции нельзя.
3. **Какие методы входят в стандартный интерфейс `Iterator`?**
   *Ответ*: `rewind()`, `valid()`, `current()`, `key()`, `next()`.
4. **Можно ли передать данные обратно в генератор?**
   *Ответ*: Да, с помощью метода `$generator->send($value)`, что превращает генератор в двунаправленную корутину.
