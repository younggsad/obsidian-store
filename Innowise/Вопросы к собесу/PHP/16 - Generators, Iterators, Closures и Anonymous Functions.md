# 16 — Generators, Iterators, Closures и Anonymous Functions

## 1. Теория

### Генераторы (Generators)
- Позволяют писать код, использующий итерацию, без необходимости заранее выделять память под весь массив данных (ленивые вычисления / Lazy evaluation).
- Используют ключевое слово `yield` вместо `return`.
- Функция-генератор возвращает экземпляр класса `Generator`, реализующего интерфейс `Iterator`.

### Итераторы (Iterators)
- Стандартный интерфейс `Iterator` (часть SPL) позволяет объектам управлять собственным поведением при проходе в цикле `foreach` (`rewind()`, `valid()`, `current()`, `key()`, `next()`).

### Замыкания и анонимные функции
- **Anonymous Functions (Closures)**: Функции без имени, которые могут присваиваться переменным.
- Захват внешних переменных осуществляется через конструкцию `use ($var)`.
- **Arrow Functions (Стрелочные функции, PHP 7.4+)**: `fn($x) => $x + $y`. Автоматически захватывают переменные из внешней области видимости по значению (Implicit value capture).

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

// Генератор для эффективного чтения больших наборов данных
function getLines(string $filename): \Generator {
    $file = fopen($filename, 'r');
    while (($line = fgets($file)) !== false) {
        yield trim($line);
    }
    fclose($file);
}

// Стрелочная функция (Arrow function)
$factor = 10;
$multiplier = fn($n) => $n * $factor; // $factor захватывается автоматически
echo $multiplier(5); // 50
```

## 3. Вопросы на собеседовании

1. **В чем главное преимущество генераторов (`yield`) перед обычным возвратом массивов?**
   *Ответ*: Генераторы возвращают элементы по одному «на лету», не загружая весь набор данных в оперативной памяти. Это критически важно при обработке больших файлов или огромных выборок из БД.
2. **В чем разница между анонимными функциями (Closures) и стрелочными функциями (Arrow Functions)?**
   *Ответ*: Стрелочные функции (`fn($x) => ...`) короче по синтаксису и автоматически захватывают внешние переменные **по значению** (implicit by-value capture). Обычные замыкания требуют явного перечисления захватываемых переменных через ключевое слово `use ($var)`.
3. **Какие методы входят в стандартный интерфейс `Iterator` в PHP?**
   *Ответ*: Пять методов: `rewind()` (возврат в начало), `valid()` (проверка наличия элемента), `current()` (текущее значение), `key()` (текущий ключ), `next()` (переход к следующему элементу).
