## 1. Фундаментальная теория и архитектура

### Интерфейсы (Interfaces)
- Чистый контракт: задает сигнатуры публичных методов, которые класс обязан реализовать. Не содержат состояния (свойств) и реализации.
- Класс может реализовывать любое количество интерфейсов.

### Трейты (Traits)
- Механизм горизонтального повторного использования кода. Позволяют внедрять наборы методов в классы.
- Разрешение конфликтов при совпадении имен методов в трейтах осуществляется через операторы `insteadof` и `as`.

### Абстрактные классы
- Промежуточное звено между интерфейсами и конкретными классами: могут содержать как реализованные методы и свойства, так и абстрактные сигнатуры.

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

trait Timestampable {
    private ?\DateTimeImmutable $createdAt = null;

    public function setCreatedAt(\DateTimeImmutable $date): void {
        $this->createdAt = $date;
    }

    public function getCreatedAt(): ?\DateTimeImmutable {
        return $this->createdAt;
    }
}

interface EntityInterface {
    public function getId(): int;
}

class UserEntity implements EntityInterface {
    use Timestampable;

    public function __construct(private int $id) {}

    public function getId(): int {
        return $this->id;
    }
}
```

## 3. Детальные вопросы на техническом собеседовании

1. **В чем разница между интерфейсом, трейтом и абстрактным классом?**
   *Ответ*: Интерфейс задает чистый контракт без логики и состояния. Трейт инкапсулирует переиспользуемый набор методов для горизонтального внедрения. Абстрактный класс задает базовую реализацию и состояние для иерархии родственных классов (вертикальное наследование).
2. **Как разрешить конфликт имен методов, если класс использует два трейта с одинаковыми методами?**
   *Ответ*: С помощью ключевых слов `insteadof` (указывает, чей именно метод использовать) и `as` (позволяет создать псевдоним для конфликтующего метода).
3. **Может ли трейт содержать абстрактные методы?**
   *Ответ*: Да, трейт может объявлять абстрактные методы, и класс, использующий этот трейт, обязан предоставить их реализацию.
4. **Может ли интерфейс содержать статические методы или константы?**
   *Ответ*: Начиная с PHP 8, интерфейсы могут содержать константы и статические методы, которые реализующие классы обязаны предоставить.
