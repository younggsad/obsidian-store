## 1. Фундаментальная теория и архитектура

### Система типов PHP (Type System)
PHP поддерживает динамическую типизацию с возможностью включения строгой проверки (`declare(strict_types=1);`). Типы делятся на скалярные, сложные и специальные:
- **Скалярные**: `int`, `float`, `string`, `bool`.
- **Сложные**: `array`, `object`, `callable`, `iterable`.
- **Специальные**: `null`, `resource`.

### Эволюция системы типов в PHP 8.x
- **Union Types (`A|B`)**: Позволяют принимать или возвращать несколько разрешенных типов.
- **Intersection Types (`A&B`)**: Требуют реализации сразу нескольких интерфейсов или классов.
- **Mixed**: Эквивалентно `array|bool|float|int|object|resource|string|null`.
- **Void**: Функция не возвращает значимого результата.
- **Never**: Функция завершает выполнение принудительно (исключение или `exit`), управление не возвращается.
- **False / True в качестве автономных типов**: Удобно для функций, возвращающих статус операции.

### Type Juggling vs Type Casting
- **Type Juggling (неявное приведение)**: PHP автоматически конвертирует типы в зависимости от контекста оператора (например, арифметика со строками).
  - *Опасность*: Сравнение через `==` приводит к неявным манипуляциям типами (например, строку `"0e12345"` ложный интерпретатор может приравнять к числу `0`, так как это научная нотация).
- **Type Casting (явное приведение)**: Принудительное указание типа через конструкции вроде `(int)`, `(string)`, `(array)`, `(bool)`, `(float)`.

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

// Современная типизация в PHP 8.2+
class OrderManager {
    public function process(int|string $identifier, \Countable&\Iterator $items): mixed {
        if (count($items) === 0) {
            throw new \InvalidArgumentException("Items collection cannot be empty.");
        }
        return "Processed ID: {$identifier}";
    }
}

// Пример неявного приведения типа (Type Juggling) и его подводных камней
$sum = "10 apples" + 5; // Вернет 15 (PHP извлекает число с левого края строки)
```

## 3. Детальные вопросы на техническом собеседовании

1. **Что такое `strict_types=1` и на что именно оно влияет?**
   *Ответ*: Директива включает строгую типизацию для **скалярных** аргументов и возвращаемых значений. Если в функцию передать `string` вместо ожидаемого `int`, PHP выбросит `TypeError`. Важно: директива действует только в том файле, где она объявлена (включается вверху файла).
2. **Какова специфика работы нестрогого сравнения (`==`) в PHP с точки зрения безопасности?**
   *Ответ*: Нестрогое сравнение выполняет Type Juggling. Это приводит к уязвимостям (magic hashes), когда хэши паролей или токены могут совпасть с нулем или друг с другом при сравнении через `==` (например, `"0e1234"` == `"0e5678"` вернет `true`). Всегда используйте строгое сравнение `===`.
3. **Для чего нужен тип `never` и чем он отличается от `void`?**
   *Ответ*: `void` означает, что функция возвращает управление в точку вызова, но без значения. `never` гарантирует, что функция никогда не вернет управление (вызывает `exit()` или выбрасывает исключение), что позволяет статическим анализаторам корректно выстраивать граф выполнения.
4. **Что такое Intersection Types и в каких сценариях они используются?**
   *Ответ*: Intersection types (`A&B`) требуют, чтобы объект удовлетворял одновременно нескольким контрактам (интерфейсам). Полезно для сложных сервисов, принимающих объекты, совмещающие несколько ролей (например, `LoggerInterface&ResettableInterface`).
