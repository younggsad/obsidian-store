# 03 — Типы данных. Type System, Type Juggling, Type Casting

## 1. Теория

### Система типов PHP (Type System)
PHP поддерживает скалярные, сложные и специальные типы данных:
1. **Скалярные**:
   - `int` (целое число)
   - `float` (число с плавающей точкой / double)
   - `string` (строка)
   - `bool` (логический: `true` / `false`)
2. **Сложные (Compound)**:
   - `array` (массив / упорядоченная карта)
   - `object` (экземпляр класса)
   - `callable` (функция обратного вызова)
   - `iterable` (псевдотип, объединяющий `array` и `Traversable`)
3. **Специальные**:
   - `null` (отсутствие значения)
   - `resource` (ссылка на внешнее системное соединение: файл, сокет, БД)

### Современные типы в сигнатурах (PHP 8.x)
- **Union Types**: `int|string` (объединение типов).
- **Intersection Types**: `Countable&Iterator` (пересечение типов).
- **Mixed**: Любой тип (`mixed`).
- **Never**: Функция никогда не возвращает управление (например, выбрасывает исключение или завершает скрипт через `exit`).
- **Void**: Функция ничего не возвращает.

### Type Juggling и Type Casting
- **Type Juggling (неявное приведение)**: PHP автоматически преобразует типы в зависимости от контекста (например, `'5' + 5` даст `10`).
- **Type Casting (явное приведение)**: Принудительное преобразование оператором приведения в скобках (`(int)`, `(string)`, `(bool)`, `(array)`, `(object)`, `(unset)`).

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

// Явное приведение типов (Type Casting)
$strNumber = "42.5abc";
$intVal = (int)$strNumber; // 42 (строка парсится слева направо до некорректного символа)

// Union types и Mixed в PHP 8+
function processInput(int|string $input): mixed {
    if (is_int($input)) {
        return $input * 2;
    }
    return strtoupper($input);
}

// Never тип
function redirect(string $url): never {
    header("Location: " . $url);
    exit;
}
```

## 3. Вопросы на собеседовании

1. **Что такое Type Juggling и каковы подводные камни неявного приведения типов?**
   *Ответ*: Это автоматическое преобразование типов PHP. Опасность в нестрогом сравнении (`==`): например, `"0e12345"` равно `"0e98765"`, так как обе строки интерпретируются как научная нотация числа ноль (магический хэш-баг).
2. **Какая разница между типами `void` и `never`?**
   *Ответ*: `void` означает, что функция завершается нормально, но не возвращает никакого полезного значения (неявный `return null`). `never` означает, что функция **никогда** не вернет управление вызывающему коду (вызывает `exit()` или выбрасывает исключение).
3. **Что такое Intersection Types и где они применяются?**
   *Ответ*: Intersection types (`ClassA&ClassB`) требуют, чтобы переданный объект реализовывал сразу несколько интерфейсов или наследовал указанные классы одновременно. Появились в PHP 8.1.
4. **Что возвращает функция `gettype()` и почему для проверки типов лучше использовать `is_*()` функции?**
   *Ответ*: `gettype()` возвращает строковое наименование типа (медленно и зависит от локали/версий). Функции `is_int()`, `is_string()` работают быстрее, безопаснее и возвращают булево значение.
