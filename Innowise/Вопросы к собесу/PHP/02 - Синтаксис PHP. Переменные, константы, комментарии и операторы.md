# 02 — Синтаксис PHP. Переменные, константы, комментарии и операторы

## 1. Теория

### Переменные и область видимости
- Переменные в PHP начинаются со знака доллара (`$`), за которым следует имя переменной (`$variable`). Имя чувствительно к регистру (`$var` и `$Var` — разные переменные).
- Переменные по умолчанию присваиваются **по значению** (Value Assignment), но объекты всегда присваиваются и передаются **по ссылке** (точнее, через указатель на идентификатор объекта).
- **Переменные переменные** (Variable variables): `${$var}` или `$$var` — позволяют использовать значение одной переменной в качестве имени другой.

### Константы
- Константы задаются один раз и не могут быть изменены во время выполнения скрипта.
- Способы объявления:
  1. `define('CONSTANT_NAME', value)` — глобальные константы, могут определяться динамически в рантайме.
  2. `const CONSTANT_NAME = value;` — константы классов или глобальной области видимости, определяются на этапе компиляции (нельзя использовать внутри условий или функций).
- Магические константы: `__LINE__`, `__FILE__`, `__DIR__`, `__FUNCTION__`, `__CLASS__`, `__METHOD__`, `__NAMESPACE__`.

### Операторы
- **Арифметические**: `+`, `-`, `*`, `/`, `%`, `**` (возведение в степень).
- **Сравнения**: `==` (равно с приведением типов), `===` (тождественно равно, без приведения типов), `!=`, `!==`, `<`, `>`, `<=`, `>=`, `<=>` (Spaceship operator, возвращает -1, 0, 1).
- **Логические**: `&&` и `and`, `||` и `or`, `!` (нотирование), `xor`. (Разница между `&&` и `and` — в приоритете операторов).
- **Операторы объединения с null**:
  - `??` (Null Coalescing): возвращает первый операнд, если он существует и не `null`, иначе второй.
  - `??=` (Null Coalescing Assignment): присваивает значение, если переменная равна `null`.

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

// Константы
define('API_VERSION', 'v1');
const TIMEOUT = 30;

// Переменные и оператор Spaceship
$a = 10;
$b = 20;
$comparison = $a <=> $b; // результат: -1

// Null Coalescing Operator
$config = [];
$host = $config['host'] ?? 'localhost'; // 'localhost'

// Null Coalescing Assignment
$userSettings['theme'] ??= 'dark';
```

## 3. Вопросы на собеседовании

1. **В чем разница между `define()` и ключевым словом `const`?**
   *Ответ*: `const` объявляет константы во время компиляции (compile-time), не может использоваться внутри условных блоков (`if`) и функций. `define()` работает в рантайме (run-time), может создаваться динамически.
2. **Как работают переменные переменные (`$$var`)?**
   *Ответ*: Значение одной переменной используется в качестве имени другой переменной (`$name = 'foo'; $$name = 'bar';` создаст `$foo = 'bar'`). На практике усложняют анализ кода и снижают читаемость.
3. **В чем разница между операторами `==` и `===`?**
   *Ответ*: `==` выполняет сравнение на равенство с предварительным приведением типов (Type Juggling). `===` проверяет строгое тождество: значения должны быть равны и иметь одинаковый тип данных.
4. **Что делает оператор `<=>` (Spaceship)?**
   *Ответ*: Возвращает `-1`, если левый операнд меньше правого; `0`, если они равны; и `1`, если левый операнд больше правого. Удобно для использования в функциях сортировки (`usort`).
