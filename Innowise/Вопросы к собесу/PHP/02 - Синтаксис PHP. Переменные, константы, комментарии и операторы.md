## 1. Фундаментальная теория и архитектура

### Переменные и символьная таблица
- Имена переменных в PHP чувствительны к регистру (`$data` и `$DATA` — разные переменные).
- Переменные хранятся во внутренних структурах данных (Symbol Tables) Zend Engine.
- **Присвоение по значению vs по ссылке**: По умолчанию скалярные типы и массивы присваиваются по значению. Объекты в PHP всегда содержат дескриптор (указатель на экземпляр в памяти), поэтому передаются «по ссылке на объект». Явное создание ссылки делается через амперсанд (`$a = &$b`).
- **Переменные переменные (`$$var`)**: Позволяют динамически формировать имена переменных. На практике считаются антипаттерном, так как затрудняют статический анализ кода.

### Константы
- **`define('NAME', value)`**: Объявляется в рантайме (выполняется при достижении строки кода). Может быть условием (`if`).
- **`const NAME = value;`**: Объявляется на этапе компиляции (compile-time). Не может находиться внутри условий или функций. Регистрочувствительна (по соглашению пишутся в UPPER_CASE).
- **Магические константы**: Динамически изменяют свое значение в зависимости от места вызова (`__LINE__`, `__FILE__`, `__DIR__`, `__FUNCTION__`, `__CLASS__`, `__TRAIT__`, `__METHOD__`, `__NAMESPACE__`).

### Операторы и их приоритет
- **Spaceship operator (`<=>`)**: Возвращает `-1`, `0` или `1` в зависимости от соотношения левого и правого операндов.
- **Null Coalescing (`??`)** и **Null Coalescing Assignment (`??=`)**: Удобные операторы проверки на `null` и существование ключа.
- **Приоритет логических операторов**: Операторы `&&` и `||` имеют более высокий приоритет, чем `and` и `or`. Это частый источник трудноуловимых багов в условиях.

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

// Демонстрация приоритета операторов
$boolAnd1 = true && false; // false (приоритет выше)
$boolAnd2 = true and false; // true (присваивание '=' имеет приоритет выше, чем 'and')

// Практичное использование Null Coalescing Assignment
$userConfig = [];
$userConfig['timeout'] ??= 60; // Установит 60, так как ключ отсутствовал

// Использование магических констант для логирования
class DatabaseConnection {
    public function connect(): void {
        sprintf("Called from method %s in file %s on line %d", 
            __METHOD__, __FILE__, __LINE__
        );
    }
}
```

## 3. Детальные вопросы на техническом собеседовании

1. **В чем разница в приоритете между `&&` и `and`?**
   *Ответ*: `&&` имеет высокий приоритет, а `and` — очень низкий (ниже оператора присваивания `=`). Пример: `$res = true && false;` запишет `false`, а `$res = true and false;` сначала выполнит `$res = true`, а затем `and false`, оставив в `$res` значение `true`.
2. **Как работают константы `const` и `define()` под капотом?**
   *Ответ*: `const` обрабатывается на этапе компиляции (статическое разрешение), что делает их немного быстрее и позволяет использовать вне функций. `define()` регистрирует константу в таблице констант в рантайме.
3. **Что такое динамические (переменные) переменные и почему их избегают в enterprise-разработке?**
   *Ответ*: Это конструкция вида `$$var`. Они сильно ухудшают читаемость кода, делают невозможным эффективный статический анализ IDE и анализ безопасности.
4. **В чем разница между присвоением объекта и присвоением скаляра в PHP?**
   *Ответ*: Скалярные типы копируют значение. Объекты хранят ссылку (handle) на структуру в памяти; при присвоении копируется только ссылка, а сам объект остается прежним (оба объекта указывают на одну область памяти).
