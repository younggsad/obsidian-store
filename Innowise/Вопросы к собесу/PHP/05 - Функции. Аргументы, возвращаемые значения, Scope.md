## 1. Фундаментальная теория и архитектура

### Объявление функций и передача аргументов
- **По значению vs по ссылке**: По умолчанию аргументы передаются по значению (создается локальная копия). Передача по ссылке (`&$arg`) передает оригинальную область памяти.
- **Variadic functions (Распаковка / Rest parameters)**: Синтаксис `...$args` позволяет принимать произвольное число аргументов в виде массива.
- **Named Arguments (Именованные аргументы, PHP 8.0+)**: Позволяют передавать аргументы по имени параметров, пропуская аргументы со значениями по умолчанию и не завися от их порядка.

### Области видимости (Scope) и Lifetime
- **Function Scope**: Переменные внутри функции изолированы от глобального контекста.
- **Static variables (`static`)**: Инициализируются единожды при первом вызове функции в рамках жизненного цикла запроса и сохраняют свое состояние между вызовами.
- **Closures (Замыкания) и Анонимные функции**: Функции без имени. Могут захватывать переменные из родительской области видимости через конструкцию `use ($var)`.

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

class OrderService {
    // Использование именованных аргументов и variadic
    public function calculateTotal(float $taxRate, float ...$prices): float {
        $subtotal = array_sum($prices);
        return $subtotal + ($subtotal * $taxRate);
    }
}

$service = new OrderService();
$total = $service->calculateTotal(taxRate: 0.2, prices: 100.0, 200.0, 300.0);
```

## 3. Детальные вопросы на техническом собеседовании

1. **Какие преимущества дают именованные аргументы (Named Arguments) в PHP 8?**
   *Ответ*: Повышают читаемость кода при вызове методов со множеством опциональных параметров, позволяют явно документировать передаваемые значения и не зависеть от порядка следования аргументов в сигнатуре.
2. **Как ведут себя статические переменные внутри функций в условиях многопоточных рантаймов (Swoole, RoadRunner)?**
   *Ответ*: В долгоживущих рантаймах состояние статических переменных сохраняется **между разными HTTP-запросами**, так как процесс PHP не завершается после одного запроса. Это может стать причиной утечки состояния и багов, если переменная не сбрасывается принудительно.
3. **В чем разница между передачей аргументов по ссылке и возвратом объекта?**
   *Ответ*: Передача по ссылке позволяет функции изменять скалярную переменную или заменять весь массив снаружи. Возврат объекта или изменение его свойств через методы является более чистым и безопасным ООП-подходом, чем передача аргументов по ссылке.
4. **Как работают замыкания (Closures) с захватом переменных по ссылке?**
   *Ответ*: При захвате переменной через `use (&$var)` замыкание получает прямую ссылку на внешнюю переменную, и любые изменения внутри замыкания отразятся во внешней области видимости.
