# 05 — Функции. Аргументы, возвращаемые значения, Scope

## 1. Теория

### Объявление и аргументы
- Функции объявляются ключевым словом `function`.
- **Передача аргументов**:
  - По значению (по умолчанию).
  - По ссылке (`&$arg`).
  - Распаковка аргументов / Variadic functions (`...$args`, аналог Rest parameters).
  - Именованные аргументы (Named Arguments, PHP 8.0+) — позволяют передавать аргументы по имени параметра независимо от их порядка.
- **Значения по умолчанию**: Должны быть константными выражениями. Обязательные аргументы не могут идти после необязательных.

### Область видимости (Scope)
- **Global Scope**: Переменные вне функций. Недоступны внутри функций автоматически.
- **Function Scope**: Переменные внутри функции изолированы.
- Ключевое слово `global` или суперглобальный массив `$GLOBALS` позволяют получить доступ к глобальным переменным внутри функций (считается антипаттерном).
- **Статические переменные (`static`)**: Сохраняют свое значение между вызовами функции в рамках жизненного цикла запроса.
- **Замыкания (Closures)**: Анонимные функции, способные захватывать переменные из внешней области видимости через ключевое слово `use`.

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

// Именованные аргументы (PHP 8+)
function createUser(string $name, int $age, string $role = 'user'): array {
    return compact('name', 'age', 'role');
}

$user = createUser(age: 25, name: 'Alice');

// Статическая переменная внутри функции
function counter(): int {
    static $count = 0;
    return ++$count;
}

echo counter(); // 1
echo counter(); // 2
```

## 3. Вопросы на собеседовании

1. **Что такое именованные аргументы (Named Arguments) и какие преимущества они дают?**
   *Ответ*: Позволяют передавать аргументы функции, указывая их имена (`foo(b: 2, a: 1)`). Это повышает читаемость кода, позволяет пропускать аргументы со значениями по умолчанию и не зависит от порядка следования параметров.
2. **Как работают статические переменные внутри функций (`статическая область видимости`)?**
   *Ответ*: Переменная инициализируется один раз при первом вызове функции и сохраняет свое значение между последующими вызовами в течение всего HTTP-запроса.
3. **В чем разница между передачей аргументов по значению и по ссылке?**
   *Ответ*: По значению передается копия данных (оригинал не изменяется). По ссылке (`&$var`) передается указатель на ячейку памяти оригинала, поэтому любые изменения внутри функции отразятся на внешней переменной.
