# 13 — ООП. Магические методы и перегрузка

## 1. Теория

### Магические методы (Magic Methods)
Магические методы — это специальные методы, которые автоматически вызываются PHP при наступлении определенных событий или обращении к несуществующим свойствам/методам:
- `__construct()` / `__destruct()` — создание и уничтожение объекта.
- `__get($name)` / `__set($name, $value)` — чтение и запись защищенных/несуществующих свойств.
- `__isset($name)` / `__unset($name)` — проверка через `isset()` и удаление `unset()`.
- `__call($name, $arguments)` / `__callStatic($name, $arguments)` — вызов несуществующих методов (объектных или статических).
- `__toString()` — преобразование объекта в строку.
- `__invoke()` — вызов объекта как функции (`$object()`).
- `__clone()` — клонирование объекта.
- `__sleep()` / `__wakeup()` — сериализация и десериализация.

---

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

class Collection {
    private array $data = [];

    public function __set(string $key, mixed $value): void {
        $this->data[$key] = $value;
    }

    public function __get(string $key): mixed {
        return $this->data[$key] ?? null;
    }

    // Вызов объекта как функции
    public function __invoke(): int {
        return count($this->data);
    }
}

$c = new Collection();
$c->name = 'Items'; // сработает __set
echo $c();          // сработает __invoke, выведет 1
```

## 3. Вопросы на собеседовании

1. **Какие минусы использования магических методов (`__get`, `__set`, `__call`) вы знаете?**
   *Ответ*: Магические методы снижают производительность (интерпретатору требуется больше времени на динамическое разрешение вызовов), ухудшают поддержку IDE (автодополнение кода работает хуже) и усложняют статический анализ.
2. **Как работает метод `__clone()` и чем он отличается от обычного присвоения объекта?**
   *Ответ*: Присвоение переменной с объектом копирует лишь ссылку на него. Клонирование (`$obj2 = clone $obj1;`) создает поверхностную копию объекта. Метод `__clone()` вызывается автоматически во время клонирования и позволяет выполнить глубокое копирование (deep copy) вложенных объектов.
3. **Для чего предназначен магический метод `__invoke()`?**
   *Ответ*: Позволяет вызывать экземпляр класса как обычную функцию (`$object($arg)`). Полезно для создания callable-объектов (например, Single-Action Controllers или middleware).
