# 27 — Асинхронность, процессы, Fibers и параллелизм

## 1. Теория

### Синхронная природа PHP
Традиционно PHP работает в блокирующем синхронном режиме (один запрос — один процесс/поток). Однако современные потребности требуют параллелизма:
1. **Многопроцессность**: Использование расширения `pcntl` и класса `Symfony/Process` для запуска фоновых процессов ОС.
2. **Многопоточность / Асинхронность**: Расширения `pthreads` (устаревшее), `Swoole`, `RoadRunner`, `ReactPHP`.
3. **Fibers (Волокна, PHP 8.1+)**: Низкопримитивная основа для реализации кооперативной многозадачности (Green threads / Coroutines). Позволяют приостанавливать и возобновлять выполнение кода из любой точки стека вызовов, что лежит в основе асинхронных фреймворков.

---

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

// Демонстрация PHP Fibers (Кооперативная многозадачность)
$fiber = new \Fiber(function (): void {
    echo "Fiber started\n";
    $value = \Fiber::suspend('suspended'); // Приостановка работы
    echo "Fiber resumed with: {$value}\n";
});

$output = $fiber->start(); // Запуск
echo "Main: {$output}\n";

$fiber->resume('hello back'); // Возобновление волокна
```

## 3. Вопросы на собеседовании

1. **Что такое Fibers в PHP 8.1 и какую проблему они решают?**
   *Ответ*: Fibers — это легковесные кооперативные потоки (зеленые потоки). Они предоставляют инфраструктуру для реализации асинхронного неблокирующего ввода-вывода (I/O) без необходимости использовать сложные callbacks, позволяя приостанавливать выполнение скрипта и возвращать управление в event loop.
2. **В чем разница между конкурентностью (Concurrency) и параллелизмом (Parallelism)?**
   *Ответ*: Конкурентность — это способность системы обрабатывать несколько задач одновременно (переключаясь между ними, как в Event Loop). Параллелизм — это физическое выполнение нескольких задач одновременно на разных ядрах процессора (мультипроцессность).
3. **Как организовать асинхронную обработку задач в традиционном PHP-монолите?**
   *Ответ*: Через очереди сообщений (RabbitMQ, Redis, Beanstalkd) и фоновые воркеры, запускаемые через CLI (например, Laravel Queue или Symfony Messenger).
