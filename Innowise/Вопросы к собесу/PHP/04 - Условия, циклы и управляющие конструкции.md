# 04 — Условия, циклы и управляющие конструкции

## 1. Теория

### Условные конструкции
- `if / elseif / else` — классическое ветвление.
- **Alternative Syntax**: Синтаксис с двоеточием (`if (...): ... endif;`) часто используется в шаблонизаторах или HTML-вставках.
- **Match expression (PHP 8.0+)**: Строгая альтернатива `switch`.
  - Сравнивает значения строго (`===`).
  - Возвращает значение (можно присвоить переменной).
  - Не требует `break` (нет проваливания / fall-through).
  - Выбрасывает `UnhandledMatchError`, если ни одно условие не подошло и нет ветки `default`.

### Циклы
- `while` и `do-while` — циклы с предусловием и постусловием.
- `for` — классический счетчик.
- `foreach` — итерация по массивам и объектам (`Traversable`). Поддерживает работу по ссылке (`&$value`) и распаковку элементов.
- Управляющие операторы: `break` (выход из цикла), `continue` (переход к следующей итерации), `goto` (крайне не рекомендуется).

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

// Match expression (PHP 8+)
$statusCode = 200;

$message = match ($statusCode) {
    200, 201 => 'Success',
    400, 422 => 'Bad Request',
    404 => 'Not Found',
    500 => 'Server Error',
    default => 'Unknown status',
};

// Foreach по ссылке
$numbers = [1, 2, 3];
foreach ($numbers as &$num) {
    $num *= 2;
}
unset($num); // Важно: уничтожить ссылку на последний элемент!
```

## 3. Вопросы на собеседовании

1. **В чем главные отличия `match` от `switch`?**
   *Ответ*: `match` производит строгое сравнение (`===`), возвращает результат (может быть присвоен переменной), не имеет эффекта проваливания (`fall-through`) и требует исчерпывающего покрытия либо ветки `default`.
2. **Какая потенциальная проблема возникает при использовании `foreach` по ссылке (`&$val`)?**
   *Ответ*: Переменная ссылки `$val` сохраняется в символьной таблице после завершения цикла. Если в дальнейшем коде использовать `$val` без повторного объявления, изменение этой переменной непреднамеренно изменит последний элемент исходного массива. Требуется вызывать `unset($val)`.
3. **Как работает альтернативный синтаксис управляющих конструкций в PHP?**
   *Ответ*: Вмесыто фигурных скобок `{}` используются двоеточие `:` и ключевые слова `endif;`, `endwhile;`, `endfor;`, `endforeach;`. Широко применяется при смешивании PHP с HTML.
