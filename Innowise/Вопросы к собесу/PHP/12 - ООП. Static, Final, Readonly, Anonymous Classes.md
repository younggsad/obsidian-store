# 12 — ООП. Static, Final, Readonly, Anonymous Classes

## 1. Теория

### Static (Статические члены)
- Статические свойства и методы принадлежат самому классу, а не конкретному экземпляру.
- Вызываются через оператор разрешения области видимости (`ClassName::method()`).
- Внутри статического метода **нельзя** использовать псевдопеременную `$this`, так как объект не создан. Вместо этого используется ключевое слово `self` или `static` (для позднего статического связывания — Late Static Binding).

### Final
- Ключевое слово `final` запрещает наследование класса или переопределение конкретного метода в классах-потомках.

### Readonly (PHP 8.1 / 8.2)
- Модификатор `readonly` гарантирует неизменяемость свойств после их первичной инициализации.
- В PHP 8.2 появилась возможность объявлять `readonly` целые классы (все свойства автоматически становятся `readonly`).

### Анонимные классы (Anonymous Classes)
- Создаются на лету с помощью `new class` без предварительного объявления имени. Полезны для одноразовых объектов, моков в тестах или передачи callback-объектов.

---

## 2. Примеры кода

```php
<?php
declare(strict_types=1);

// Readonly класс (PHP 8.2+)
readonly class UserDto {
    public function __construct(
        public string $name,
        public string $email
    ) {}
}

// Анонимный класс
$logger = new class {
    public function log(string $msg): void {
        echo $msg;
    }
};

$logger->log("Anonymous class in action");
```

## 3. Вопросы на собеседовании

1. **Что такое Позднее статическое связывание (`Late Static Binding`) и как работает ключевое слово `static`?**
   *Ответ*: Позднее статическое связывание решает проблему разрешения вызовов статических методов в иерархии наследования. Ключевое слово `self` ссылается на класс, в котором написан код, а `static` ссылается на класс, который фактически вызвал метод в рантайме.
2. **В чем разница между `readonly` свойством и константой (`const`)?**
   *Ответ*: Константа задается на этапе компиляции и ее значение неизменно глобально. `readonly` свойство может быть установлено один раз в конструкторе (в рантайме), после чего его значение нельзя изменить, но оно уникально для каждого экземпляра объекта.
3. **Для чего используются анонимные классы?**
   *Ответ*: Для создания легких одноразовых объектов без засорения пространства имён именованными классами. Часто применяются в тестах для подмены зависимостей (моков) или в качестве локальных реализаций интерфейсов.
