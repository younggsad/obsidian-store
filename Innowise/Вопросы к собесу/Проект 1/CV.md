### Платформа непрерывного медицинского образования

|Поле|Значение|
|---|---|
|Период|04.2024 — по настоящее время|
|Роль на проекте|Инженер-программист|

**Описание**

Платформа непрерывного обучения на базе Moodle для сети медицинских и научных организаций. Медицинские специалисты и исследователи получают на ней курсы, аккредитованные программы повышения квалификации и учебные материалы по научной тематике. Каждая организация управляет собственными категориями курсов, оформлением и группами слушателей в рамках общей установки, а платформа обеспечивает единое управление контентом, многоязычность и общие стандарты безопасности. Решение упростило запуск новых обучающих программ и дало организациям масштабируемую основу для профессионального развития сотрудников.

**Обязанности**

- Взаимодействие с представителями организаций-партнёров: приоритизация дорожной карты платформы и перевод потребностей в обучении в конкретные задачи для разработки.
- Настройка языковых пакетов и фильтров многоязычного контента Moodle, создание локализованных каталогов курсов для организаций из разных регионов.
- Разработка local-плагина для отправки содержимого курсов и элементов в DeepL API, что автоматизировало перевод учебных материалов на несколько языков.
- Подключение глобального поиска Moodle к Apache Solr и настройка индексации курсов, форумов и ресурсов, что сократило время ответа поиска.
- Создание собственной темы на основе Boost с переопределением шаблонов Mustache, благодаря чему страницы курсов каждой организации оформлены в её фирменном стиле.
- Вынос массовых операций перевода контента и записи на курсы в плановые и ad-hoc задачи (Task API) для фоновой обработки больших объёмов данных без замедления сайта.
- Настройка аутентификации на основе SAML для единого входа (SSO) через провайдеры идентификации организаций-партнёров.
- Разработка собственного модуля активности для учёта разборов клинических случаев и прогресса в научном обучении, со своими таблицами в базе данных, правами доступа (capabilities) и формами настроек.
- Проектирование и документирование внешних функций веб-сервисов Moodle (REST) для синхронизации учётных записей и записей на курсы со сторонними системами в реальном времени.
- Мониторинг состояния платформы с помощью Grafana и Sentry: выявление медленных страниц и всплесков ошибок и их устранение до того, как они повлияют на слушателей.

### Обучающая платформа для государственного сектора

|Поле|Значение|
|---|---|
|Период|07.2022 — 04.2024|
|Роль на проекте|Инженер-программист|

**Описание**

Обучающая платформа на базе Moodle, которую европейские институты используют для обучения сотрудников и информирования граждан о деятельности институтов, общественных инициативах и изменениях в политике. Платформа включает курсы на основе официальных публикаций и объявлений, анкеты для самооценки и отчёты о прогрессе. Решение поддерживает открытую коммуникацию между институтами и обществом и делает государственную и научную информацию доступнее для изучения.

**Обязанности**

- Анализ требований заказчика и их преобразование в технические спецификации с точной оценкой объёма работ и сроков.
- Разработка собственных форматов курсов и блоков для публикации обучающих программ о политике и общественных инициативах, что упростило слушателям поиск информации об институтах.
- Создание элемента курса для анкетирования с собственным типом субплагинов, позволяющим добавлять новые типы вопросов для тестов и опросов в виде отдельных плагинов.
- Реализация многошаговой формы самооценки на Moodle Form API с мгновенным подсчётом баллов и графиками результатов на Chart.js.
- Рефакторинг существующих плагинов и перенос правок ядра в отдельные плагины для повышения надёжности, скорости загрузки страниц и упрощения обновлений.
- Разработка функций веб-сервисов REST для безопасного обмена данными между Moodle и внешними государственными сервисами.
- Сквозное тестирование и отладка, повышение стабильности и безопасности платформы и её соответствия требованиям институтов.

**Окружение**

PHP, JavaScript, Moodle, PostgreSQL, Mustache, Plugin API, Form API, DML API, Web Services API, HTML / CSS, Chart.js, Docker, Docker Compose, Linux, Composer, REST, Git / GitLab.
